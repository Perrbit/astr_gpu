# Curvilinear NSCBC viscous-source coupling design

_Approved design for the first viscous-source-coupled curved open-boundary slice in ASTR, 2026-09-12_

## Scope

This design extends the validated CURVE-C22 upper-eta non-reflecting boundary
with the viscous residual produced by ASTR's existing sixth-order explicit
Navier-Stokes diffusion operator. The admitted production path is restricted
to:

- three-dimensional, static, single-block curvilinear geometry;
- the physical upper computational eta face represented by `bctype=52`;
- the non-reacting five-equation perfect-gas system;
- nondimensional flow with Sutherland viscosity;
- `difschm=643e` and `diffterm=t`;
- lower-y `bctype=41`, x `bctype=11/21`, and periodic z boundaries;
- explicit spatial schemes and explicit Runge-Kutta integration;
- no boundary filter, sponge, species, chemistry, or turbulence model; and
- the already admitted NP=1/2/4/8 decompositions.

The curved acoustic-box configuration may also use the implementation as a
verification case. It is not a production boundary-layer case.

This phase does not claim a mathematically complete viscous open-boundary
condition for every Navier-Stokes variable. It couples the viscous residual
generated by the established ASTR diffusion closure into the incoming
characteristic relation. The result is named a
**viscous-source-coupled GCBC** until independent physical validation supports
a stronger claim.

## Decision

Use a face-only pre/post-diffusion RHS difference. Do not duplicate the
diffusion operator inside the boundary routine and do not allocate another
full three-dimensional field.

For the upper-y owner rank:

1. apply the existing inviscid source-balanced GCBC;
2. assemble the complete inviscid RHS;
3. save `qrhs(:,jm,:,1:5)` immediately before diffusion;
4. run the existing sixth-order explicit diffusion operator unchanged;
5. form the upper-face viscous residual from the RHS difference;
6. project that residual into the local eta characteristic basis;
7. subtract only its locally incoming characteristic components; and
8. leave outgoing and stationary characteristic components unchanged.

CPU and GPU use the same algebra and the same stage boundaries. The GPU face
snapshot remains device resident, and every new CUDA kernel is followed by an
explicit synchronization.

## Alternatives considered

### Recompute viscous fluxes in the GCBC kernel

This would avoid a snapshot, but it would duplicate Sutherland viscosity,
stress, heat-flux, metric transformation, halo, and sixth-order closure logic.
The duplicate implementation could differ from the actual diffusion residual
used by the time integrator. This option is rejected.

### Refactor all boundary processing into a new staged framework

An explicit boundary-stage architecture remains the long-term design for
multiple interacting open faces and stateful boundaries. It is larger than the
current upper-face requirement and would widen the regression surface without
improving this first viscous source term. This option is deferred.

### Project the complete post-diffusion RHS and zero incoming components

This is compact, but it would also remove inviscid, forcing, or future physics
contributions depending on call order. The face-difference contract isolates
the established diffusion operator and is therefore selected.

## Mathematical contract

ASTR advances the conservative transformed state with an RHS of the form

\begin{equation}
\frac{\partial \widehat{\boldsymbol{Q}}}{\partial t}
=
-J\boldsymbol{P}\boldsymbol{L}
-\boldsymbol{S}_{i}
+\boldsymbol{D}_{v},
\end{equation}

where $\boldsymbol{S}_{i}$ contains the existing metric and transverse
inviscid source, and $\boldsymbol{D}_{v}$ is the discrete viscous flux
divergence added by `diffrsdcal6` or the matching GPU diffusion path.

CURVE-C22 uses

\begin{equation}
\boldsymbol{C}_{i}
=\frac{1}{J}\boldsymbol{P}^{-1}\boldsymbol{S}_{i},
\qquad
L_m=-C_{i,m}
\quad \text{for incoming modes}.
\end{equation}

With viscosity, define

\begin{equation}
\boldsymbol{C}_{v}
=\frac{1}{J}\boldsymbol{P}^{-1}\boldsymbol{D}_{v}.
\end{equation}

The source-balanced viscous characteristic condition is

\begin{equation}
L_m^{\mathrm{bc}}=-C_{i,m}+C_{v,m}
\quad \text{for incoming modes}.
\end{equation}

Because CURVE-C22 has already inserted $-C_{i,m}$, this phase applies the
equivalent conservative RHS correction

\begin{equation}
\boldsymbol{RHS}_{\mathrm{bc}}
\leftarrow
\boldsymbol{RHS}_{\mathrm{bc}}
-J\boldsymbol{P}\boldsymbol{M}_{\mathrm{in}}\boldsymbol{C}_{v},
\end{equation}

where $\boldsymbol{M}_{\mathrm{in}}$ is diagonal and equals one only for
$\lambda_m<-\epsilon_{\lambda}$. The local wave speeds, outward normal, and
roundoff tolerance are unchanged from CURVE-C22:

\begin{equation}
\lambda_m=(u_n,u_n,u_n,u_n+c,u_n-c),
\qquad
u_n=\boldsymbol{u}\cdot\frac{\nabla\eta}{\lVert\nabla\eta\rVert}.
\end{equation}

The correction therefore makes the incoming component of the complete
inviscid-plus-viscous RHS zero while preserving outgoing viscous transport.

## Discrete stage contract

### CPU

The CPU implementation hooks into `rhscal` after convective sign conversion
and before `diffrsdcal6`:

```text
assemble inviscid residual including upper-y GCBC
qrhs = -qrhs
capture upper-y pre-diffusion qrhs
diffrsdcal6(..., physical_boundary_rhs=.true.)
apply upper-y viscous characteristic correction
write full-RHS validation snapshot
```

The face buffer is allocated lazily only when the restricted viscous
non-reflecting capability is active. It stores five FP64 values for each local
upper-face point. The capture/apply pair has a strict ready-state guard so a
stale buffer cannot be consumed.

### GPU

The GPU orchestration mirrors the CPU sequence:

```text
assemble inviscid RHS
capture_upper_y_prediff_rhs_kernel
explicit synchronization
existing diffusion flux, halo, and RHS kernels
upper_y_viscous_characteristic_correction_kernel
explicit synchronization
case sources
```

The buffer shape is `(0:im,0:km,1:5)` on the upper-y owner only. It is
allocated once and remains on the device. No host copy or new MPI exchange is
introduced because the correction consumes the already assembled local
upper-face diffusion residual. Existing diffusion halo exchange remains the
sole communication owner.

## Ownership and corner rules

- Only a rank owning the physical upper-y face captures or corrects the RHS.
- The face includes all local `i=0:im` and `k=0:km` points, matching CURVE-C22.
- x-boundary and periodic-z corner values use the diffusion residual already
  produced by the established full-face diffusion closure.
- No local periodic remapping of Jacobian or metric data is allowed at MPI
  interfaces.
- The characteristic normal always uses `dxi(i,jm,k,2,:)`.
- A non-positive Jacobian, zero metric norm, non-positive sound speed, missing
  capture, or non-finite viscous residual is a hard error in validation and a
  rejected capability in normal execution.

## Capability contract

Keep the inviscid CURVE-C22 predicate unchanged. Add a separate named viscous
predicate so that admitting `diffterm=t` cannot silently broaden the inviscid
case. The viscous predicate requires all scope conditions above and is routed
through:

- GPU first-stage capability validation;
- CPU/GPU conservative boundary selection;
- full-face physical diffusion accumulation;
- face capture and correction; and
- validation snapshot ownership.

The runtime string remains:

```text
ASTR_NSCBC_FARFIELD_MODE=nonreflecting
```

No second user-facing mode is added because viscosity changes the source term,
not the incoming-wave policy.

## Validation design

Implementation follows test-driven development. Each behavior must first be
represented by a failing test that fails because the viscous capability or
algebra is absent.

### Algebra and sign gate

A manufactured five-component viscous residual is projected with the
production CPU and GPU characteristic helpers. Tests cover subsonic outflow,
subsonic inflow, supersonic outflow, supersonic inflow, and roundoff-level
normal velocity. Acceptance requires:

- incoming complete characteristic RHS at or below `1e-12`;
- outgoing and stationary components unchanged at or below `1e-12`; and
- CPU/GPU correction agreement at or below `1e-12`.

The test must fail if the viscous correction sign is reversed.

### Uniform viscous-flow gate

Run the curved acoustic-box configuration with `diffterm=t`. A uniform field
has zero stress and heat-flux divergence, so the viscous correction must be
zero to roundoff. Require CPU/GPU full-field error at or below `1e-10`, uniform
drift at or below `1e-12`, and finite fields.

### Curved viscous acoustic gate

Use the existing compact-support outgoing acoustic pulse with viscosity
enabled and matched CPU/GPU grids. Preserve the existing characteristic-energy
definition, but compare each viscous run with its matching CPU result rather
than reusing the inviscid reflection threshold without evidence. Require
CPU/GPU reflection-coefficient agreement at or below `1e-10`, full-field error
at or below `1e-10`, and decreasing reflection under the established grid
refinement sequence before assigning a new absolute physical threshold.

### Boundary-layer and topology gate

Use the existing curved Mach-5 laminar boundary-layer configuration with
`11/21,41/52`, Sutherland viscosity, and no filter. Run NP=1, all NP=2 slabs,
all admitted NP=4 planes, and NP=8 `2x2x2`. Require:

- same-topology CPU/GPU field and statistics errors at or below `1e-10`;
- wall invariants at the thresholds owned by the existing HBL gate;
- identical upper-y owner counts; and
- finite positive Jacobians and finite fields.

This is a numerical-equivalence gate, not proof of physical SBLI farfield
fidelity.

### Runtime gates

- Compute Sanitizer: NP=1 and NP=2 y-slab, zero reported errors.
- Nsight Systems: exactly one capture and one correction launch per viscous
  RHS on the upper-y owner, no launch on non-owner ranks, and no full-field
  host/device transfer introduced.
- Regression: the complete CURVE-C22 inviscid matrix must remain unchanged.

## Documentation and claim boundary

On completion, update the validation matrix and top-level status documents with
measured errors, topology coverage, sanitizer output, and profile evidence.
Use the following bounded statement:

```text
Validated: static single-block, non-reacting, five-equation curved upper-eta
viscous-source-coupled non-reflecting GCBC using ASTR's explicit 643e diffusion
residual for the tested CPU/GPU and MPI matrix.

Not validated: a general mathematically complete viscous open boundary,
filtered GCBC, target relaxation on curved faces, other open faces,
moving/multiblock grids, species, chemistry, turbulence models, or production
SBLI farfield fidelity.
```
