Grounding Context · 当前依据

已验证与未完成必须分开。IS0–IS3 的小型 TGV 统计、GPU 渲染和几何读回已有证据；IS4–IS7 的完整扩围尚未通过。256³ 展示的历史记录只完成 48/100 帧，节点附加主机内存超出 16 GiB。该失败仍要求先做 R1 生命周期、R2 分段计时和 R5 长序列验收。

历史记录显示，每帧双 rank 合计 D2H 约 1.397 GiB，桥接复制约 3.555 GiB，计算约 0.6–0.7 秒、计算加后处理约 28 秒。这些是 2026-09-30 的诊断记录，本次没有重测，也不足以证明 PCIe 是主要瓶颈。

当前正式渲染入口固定分配 11 个场分量和 14 个派生分量；C++ 桥接再复制坐标、场和派生量。与此同时，原生文件输出已有可选分量 GPU 打包及私有诊断 halo。因此，可复用的基础并非从零开始，但不能将文件输出的准入直接转成 Catalyst 的准入。

自适应输出 AP0–AP3 已有批准设计：独立监测、预设窗口和事件、两档输出、固定正式统计与 checkpoint 频率、精确续接。这是已有待实施项，不重复包装成新增建议。新完整步输出已经默认启用，旧 checkpoint 不再作为恢复接口。

当前必要工作：先处理 R1/R2 的资源与耗时归因，并完成既定输出接口衔接。下列候选不是替代主计划的新承诺；没有改变资源超限停止、完整步采样、精确续接或不追求在线交互的约束。

本次以当前单会话完成源码核对与筛选，未使用独立子代理审阅。未运行 GPU 验收、远程任务或性能测试。Confidence 为适用性判断，不是测得的加速概率。

Topic Axes · 四个考察面

  • 可靠运行与诊断：减少重复长计算，解释资源增长和阶段耗时。
  • 数据供给与搬运：字段、区域和派生量按产品需要提供。
  • 科学信息提取：低存储成本保留统计发展、壁面运动和反应流分布信息。
  • 可追溯使用：让稀疏图片和几何能按真实时间、触发原因和物理定义检索。

Ranked Ideas · 排序后的候选

  1. 按产品声明字段与派生量依赖
  2. 切片与壁面的轻量渲染通道
  3. 不推进流场的后处理回放入口
  4. 分块统计发展报告
  5. 壁面与反应流时间演变图册
  6. 图片、几何与事件的离线目录

1. 按产品声明字段与派生量依赖

Description
每个预设明确需要哪些字段、空间范围和派生量，在同一完整步合并需求。只有流线的产品不需要 q1–q5 或全部速度导数；只绘制 Q 和速度着色时，可考虑设备端形成 Q 后仅提供速度与 Q，而不是将所有梯度传入渲染器。静态坐标可按几何身份复用。
Axis
数据供给与搬运。
Basis
direct: src/insitu_session.F90:1105–1111 固定准备 11+14 分量；src/insitu_mesh_adapter.cpp:98–106 再分配并复制；src_gpu/output_fields_gpu.cuf:33–71 已有分量选择和私有诊断 halo。将 R4 的局部优化发展为明确产品契约是新增的架构价值。
Rationale
减少每帧无用计算与复制，也使未来 AIR5 字段增加时不必默认复制全部组分。多个视角或产品可共享同相位数据准备，但不能由此承诺整步加速。
Downsides
必须核对算子、完整步身份、halo 和缓存失效。原生 GPU 派生输出的网格/格式限制仍有效，不能直接推广到 CURVE。减少分量不等于消除整个管线的主机拷贝。
Confidence
90%，需求依据强，性能收益尚未测量。
Complexity
Medium。

2. 切片与壁面的轻量渲染通道

Description
为预设平面、剖面和壁面图提供小维度数据通道。只看一个切片时，不先下载三维域再让 ParaView 切片；GPU 或已有选区打包提供实际需要的节点、坐标与字段。后续壁面 Cf、热流图可沿用这一数据供给方式。
Axis
数据供给与搬运。
Basis
direct: src/output_archive.F90:439–522 已有预算化 GPU 选区打包与传输；正式渲染仍在 src/insitu_session.F90:1105–1111 处理整个局部域。external: ParaView Catalyst Blueprint 支持命名 mesh channels，而不是只能接受当前单一整域通道。
Rationale
固定平面节点数通常随二维尺度增长，整场节点数随三维尺度增长。对平板/SBLI 观察尤其有价值，也有机会复用已验证的切片文件输出基础。
Downsides
网格对齐切片与任意物理平面不同，后者需要插值；CURVE 的索引平面也不必是物理平面。法向导数仍可能需要三维邻域。不能用平面速度取代三维流线的积分场。
Confidence
85%，规模优势来自数据维度，具体开销未测。
Complexity
Medium。

3. 不推进流场的后处理回放入口

Description
将一个已封存的新 checkpoint 用于明确的只读后处理回放，在冻结场上重复运行同一个预设或比较不同预设，不执行流体/化学推进，不将重复帧计入正式时间统计。优先整理现有恢复与初始帧能力，而非另写流体推进器。
Axis
可靠运行与诊断。
Basis
direct: R1 已要求冻结场排除物理演变；src/insitu_session.F90:188–203,1135–1139 已有 native 恢复、显式渲染覆盖及恢复点出图基础，但并不等于已有完整的独立回放产品。
Rationale
能将 256³ 重复诊断中的求解成本移除，区分场演变导致的几何变化与固定输入仍增长的资源问题。相同封存状态也便于比较 CPU/GPU 派生量和显示脚本变更。
Downsides
读取 checkpoint 本身仍有 I/O 和内存成本；该 checkpoint 不自动包含任意时刻的历史场。只读回放、零步结束、统计禁累积和恢复点重绘都需要明确核对，不能假定当前 maxstep 配置已满足这些条件。
Confidence
85%，可复用基础明确，独立入口尚需设计。
Complexity
Medium。

4. 分块统计发展报告

Description
在既有时间加权均值、RMS 和应力之上，提供按模拟时间分块的可读报告：列出每块实际覆盖时长、块均值、脉动量和与前块的差异。进一步可选加入少量探针相关时间诊断，以显示哪些块仍高度相关，而不是仅看累计均值趋于平坦。
Axis
科学信息提取。
Basis
direct: 计划 1.1 已要求连续块漂移，但明确不自动判定统计定常；src/insitu_velocity_statistics.F90:12–35 当前状态围绕窗口累计量与上一份样本。新增价值是块级可解释报告和后续相关性信息，不是重复实现已有累计均值。
Rationale
服务前驱是否充分发展、是否值得继续计算的判断。块平均漂移与瞬时脉动必须分开，两个量一起呈现比单一累计均值更有用。
Downsides
分块稳定不证明平稳性。相关时间和置信区间需要明确假设、足够记录长度及非均匀采样处理；不能对自适应图片时间直接做普通等间隔 FFT，也不能在没有依据时自动停止生产任务。
Confidence
85%，已有需求明确，统计判据须另行批准。
Complexity
Medium；相关性扩展成本更高。

5. 壁面与反应流时间演变图册

Description
补充 IS5 的最终分布和位置序列，用壁面摩擦/热流的流向位置—时间图观察移动与间歇变化；对 AIR5 在选定近壁区域输出 T、Tv、组分的分布或联合分布，揭示均值和 RMS 隐藏的尾部与相关变化。
Axis
科学信息提取。
Basis
direct: 计划 1.1, IS5 已要求壁面分布、分离/再附序列和 T/Tv/五组分；1.2.1 明确几何与密度权重不能混用。reasoned: 小区域归约后的图谱和直方图可以保留演变信息，而不常规保存完整三维场。
Rationale
对真实 SBLI 和反应流，比继续增加 Q 图种类更直接回答“分离区如何运动、热流在哪里集中、非平衡状态是否局部化”。
Downsides
要先通过 IS4/IS5 相位、几何与物理定义门槛。三维局部反流不能不加定义压成单一分离长度；AIR5 热流组成不能用单组分公式代替。直方图的权重、范围、越界计数与固定分箱会影响解释。
Confidence
80%，科学用途强，但依赖后续壁面/AIR5 原位准入。
Complexity
High，相比纯 TGV 模板扩展需要更多物理检查。

6. 图片、几何与事件的离线目录

Description
建立本地可浏览的产品索引，将实际时间、完整步、触发事件或窗口、视角、字段、Q 阈值、色标、平均窗口覆盖与对应文件关联。目录只是图片/几何的派生索引，不是新的重启附属件，也不是在线控制台。
Axis
可追溯使用。
Basis
direct: scripts/insitu/tgv256_demo.py:113–118 目前记录帧身份与结束标志，自动加密后时间间隔不再恒定；计划开头指出已保存几何不能任意重选 Q 阈值或流线种子。external: Ascent 官方教程已有 Cinema 图像数据库与事件触发的先例。
Rationale
回答“为什么这一段密集、图上是什么时刻与定义”，同时便于预设多视角离线比较。避免把稀疏或不等间隔帧直接拼接后误认为视频等间隔代表物理时间。
Downsides
需要正确拼接重启段和失败段，避免将未完成帧列为成功。索引不能恢复没保存的场或重做任意 Q 阈值；多视角还会增加渲染开销。事件履历的存储预算必须明确。
Confidence
90%，小型数据即可提高解释性，不依赖全 GPU 重构。
Complexity
Low–Medium。
