# ASTR GPU 部署验收清单

文档版次：2026-09-29。本清单用于接收方在实际计算环境中完成部署检查。
已有数值检查见 [验证结果摘要](ASTR_RELEASE_LOCAL_REGRESSION_20260929.md)。
该摘要不替代目标节点的启动、通信和物理工况验收。

## 1. 源码与构建

- 保留根 CMakeLists.txt、src/、src_gpu/、user_define_module/ 和 examples/。
- 确认 LICENSE、使用说明和输入数据字典齐全。
- 使用独立构建目录，显式设置 BUILD_TESTING=OFF、CHEMISTRY=OFF。
- 非反应流基础构建设置 ASTR_WITH_AIR5_CHEMISTRY=OFF。
- 按需要设置 ASTR_WITH_CUDA；usegpu 仍是输入文件中的运行开关。
- 核对目标 GPU 架构及最终编译命令，避免沿用另一硬件环境的缓存。

## 2. 环境与依赖

- 核对编译器、MPI Fortran 包装器与实际 MPI 启动器属于兼容环境。
- 核对 HDF5 Fortran/HL 库、并行支持和编译器 ABI。
- 在实际计算节点检查动态库，既检查缺失库，也检查加载的是哪一套 MPI。
- 核对驱动、GPU 可见设备、节点内 rank 与设备映射。
- 调度器资源申请、模块及工作目录按部署方规范设置，不照搬其他平台配置。

## 3. 最小运行检查

1. 使用 Quickstart 的非反应流 TGV 完成单 rank 短跑。
2. 使用一 rank 一 GPU 完成多 rank 短跑，检查拓扑及 halo 最小尺寸。
3. 采用 FP64、explicit 同步、主机中转通信建立基线。
4. 比较 CPU/GPU 同相位场及统计量，预先明确绝对与相对误差判据。
5. 完成目标壁面或开放边界组合的短跑，不用周期 TGV 代替全部边界验收。
6. 检查所需的 checkpoint、切片和统计文件，确认字段有限、步号与时间一致。

## 4. 重启

- 分别运行连续计算与同一物理终点的分段重启计算。
- 非反应流 GPU 需携带全部 rank-local restart_q 文件、HDF5 和辅助文件。
- 精确 GPU 恢复保持模型、网格、物理配置及 MPI 拓扑一致。
- 检查统计文件是追加还是重建，按步号对齐后比较。
- AIR5 补偿和特征顶面按其专用协议恢复，不能套用五方程协议。
- 恢复文件不完整或校验失败时停止，不删除版本字段绕过检查。

## 5. 条件功能

| 功能 | 启用前检查 |
|---|---|
| CUDA-aware MPI | 编译查询、运行时支持、实际设备缓冲传输及目标边界组合 |
| 混合精度 | 对应配置获支持，并完成与同工况 FP64 的误差对照 |
| 通信重叠、减少同步、融合通量 | 满足各选项限制，保持数值一致并测量完整步耗时 |
| AIR5 | 独立启用构建，核对模型、组分、双温、保正与恢复配置 |
| 新曲线网格 | 正 Jacobian、度量、法向、边界兼容性及自由流保持 |
| 长时物理计算 | 时间步、分辨率、入口发展及统计收敛判据 |

## 6. 结果记录与放行

记录源码版本、构建选项、软件版本、硬件与资源、输入和网格版本、运行时选项、
比较相位、误差阈值及结果。结论分别标记为通过、失败或未检查。
对外共享记录前移除私有账户、登录信息、内部主机名及目录。

基础输出采用 iomode=h。s/n 遗留接口不作为完整主程序输出能力放行。
目标平台未完成上述检查时，不将“能够编译”表述为可直接生产运行。
