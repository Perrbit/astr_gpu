## 首个失效点

按物理节点检查两个 rank 的三个阶段，首个失效出现在 rank 0，
全局节点 `(2,24,71)`，坐标约 `(54,1.6820149703959528,66.5625)`。
该点处于入口吹吸区附近，不在 x+、y+ 或 MPI 接口上。

五变量状态中单位体积内能、压力与无量纲温度定义为：

\[
\rho e=q_5-\frac{q_2^2+q_3^2+q_4^2}{2q_1},\qquad
p=(\gamma-1)\rho e,\qquad T=\gamma Ma^2\frac{p}{\rho}.
\]

源实现为 `src_gpu/solver_gpu.cuf` 的 `q_to_primitive_kernel` 和
`rk3_first_update_global_kernel` / `rk3_update_global_kernel`。
诊断文件以 Fortran 顺序存储，头部为五个 int32 的 `(im,jm,km,hm,numq)`，
其后为含 halo 的 FP64 q；读取契约见 `compare_q_validation_snapshots.py`。
表中只计算物理节点，不将未定义的物理外侧 halo 当作流场。

| 相位 | 该点单位体积内能 |
|---|---:|
| 第一阶段开始 | 9.445315448673849e-5 |
| 第一阶段更新后 | 3.4398857757253834e-7 |
| 第二阶段更新后 | 4.687558046287399e-5 |
| 第三阶段更新后 | -1.889188532294521e-6 |

第三阶段后只有这一个物理节点失去保正性，其余物理节点仍有限且密度、
内能为正。坏点密度仍为 `0.07935158278679134`，压力为
`-7.556754129178085e-7`，温度约 `-0.001919862942791722`。
因此 CFL 声速计算中的 `sqrt(T)` 失效。负内能约为该点总能量的
0.0818%，不是机器舍入量级，也不是网格度量先出现 NaN。

## 空间项与 RK 更新

坏点的边界专用 RHS 为零。它不在海绵区；按捕获的 q、完整 RHS 与
几何 Jacobian 重算三个 RK 更新，最大差为 `1.39e-17`，
第三阶段差为 `3.47e-18`。没有发现该点 RK 更新公式或海绵覆盖错误。

第三阶段开始的内能瞬时变化率由守恒 RHS 计算：

\[
\frac{\mathrm d(\rho e)}{\mathrm dt}
=L_5-\boldsymbol{u}\cdot(L_2,L_3,L_4)
 +\tfrac12|\boldsymbol{u}|^2L_1.
\]

这里 L 已除以实际几何 Jacobian。方向贡献由
`conv_after_x/y/z` 的累积差取得，黏性贡献由 `full-conv` 取得。
本工况无额外体源项。

| 第三阶段贡献 | 内能瞬时变化率 |
|---|---:|
| x 对流 | -1.5502852306331922e-3 |
| y 对流 | -1.5207174118314051e-3 |
| z 对流 | -2.039378983401727e-3 |
| 黏性 | +2.882502228180225e-4 |

对流正在消耗内能，黏性项部分补偿。三个阶段该点的传感器值约为
0.6983、0.7077、0.7024，周围重构节点的激波掩码均为 1。
特征重构已启用，不能将失效解释为漏触发传感器。

## 同状态 CPU/GPU 对流复核

复用 `tests/gpu_validation/mp_ld_reconstruction_probe.cuf`，加入可选的
`ASTR_MP_LD_SNAPSHOT` 测试输入，不修改生产求解器。
从每阶段真实状态抽取 16×12×8 区间及五层 halo 的小块，保留原 x- 闭合、
原度量、原传感器掩码和重构权重 0.5。目标点映射为 `(2,6,4)`。
人为小块的 y/z 外边界不进入目标点的重构模板；以重新计算的 GPU RHS
匹配原完整域捕获值来核查截取是否忠实。

CPU 调用生产 `solver:convrsduwd`，GPU 调用生产特征重构和差分核。
统一 CPU 原函数与 GPU 的 RHS 符号后，CPU/GPU/原运行捕获值的目标点
最大绝对差分别为 `6.66e-16`、`2.22e-16`、`8.88e-16`。

## 判断与已批准动作

直接失效链路已明确：当前状态下的离散对流贡献降低内能，第三阶段
守恒更新得到负内能，随后物性及 CFL 检查主动拒绝。该点同状态对流核
没有显示 CPU/GPU 移植差异。CFL 小于 1 和 MP-LD 特征重构不保证内能保正。

当前粗化 x 网格在两个吹吸区间 `(20,40)` 与 `(40,60)` 内分别仅有
`x=27` 和 `x=54` 一个内部节点。分辨率不足是需检验的原因，不是已由
本轮诊断证明的唯一原因。不能据此认定 NSCBC 或原外推边界谁更准确。

用户已批准先做局部 x 网格敏感性检查：恢复吹吸区及其邻近区域的原始
节点并分级过渡，保持原格式、边界、吹吸参数、dt 和主滤波设置不变。
先检查是否跨过原失效时间，再决定是否启动 10000 步。

### 时间步正性预算与决策边界

固定首点第一阶段初态 q 和捕获的实际完整 RHS，令 L=RHS/J，
候选前向 Euler 状态为 q+sL。内能保正要求密度为正且

\[
 G(s)=(q_1+sL_1)(q_5+sL_5)
       -\tfrac12\left|\boldsymbol{m}+s\boldsymbol{L}_m\right|^2>0.
\]

其二次项、一次项、常数项分别为
`1.0097191204389187e-3`、`-5.872775954811761e-4`、

### 通量、完整更新与正性预算

保留原 MP7-LD 高阶界面通量 H，在同一面上用相邻两个守恒状态和平均
映射度量构造局部 Lax--Friedrichs/Rusanov 低阶通量 L，令 D=H-L。
低阶波速取两侧 `|metric dot velocity| + sound_speed*|metric|` 的最大值。
对每个内部节点的完整高阶 RHS，去除 D 的通量差得到低阶基准：

\[
R^L=R^H+\sum_{a=1}^{3}(D_{a,+}-D_{a,-}),\qquad
\overline U=(aU^nJ+bU^{(s)}J+c\Delta t R^L)/J.
\]

J 为现有静态网格 Jacobian，a/b/c 沿用原 RK3 系数。第一阶段按原
第一阶段公式构造基准。黏性、边界和体源项不从检查中删去，也不擅自限幅。
若基准的密度或内能不严格为正，停止；不能以一阶对流在某 CFL 下保正，
推断完整黏性/源项更新或任意曲线度量也保正。

每个节点分别检查六个面修正状态
`base + 6*c*dt/J*sign*theta*D`，左面取正号、右面取负号。
五变量理想气体的密度正、内能正状态集合为凸集；六个修正状态的
平均值即所需的完整受限更新。用二分搜索取得每面允许预算，再取该
节点六面预算的最小值。每个实际界面取相邻节点预算的最小值：

\[
F^{\rm limited}=L+\theta(H-L),\qquad 0\leq\theta\leq1.
\]

一个界面的五个守恒分量共用 theta，保证这是同一个 Euler 通量的凸混合。
这不是 AIR5 各组分共限方案。MPI 交界先传递权威相邻面通量，再对共享
节点预算取最小值并刷新 halo，避免两侧分别选取不同修正。私有阻塞 tag
为 21401..21406，复用预分配设备/固定主机缓冲；已有 device-aware 后端
可复用接口，但本轮仅实际测试 pinned 后端。

有限精度下二分预算向安全侧退 `256*epsilon`，并按实际 RK 运算顺序
再次检查完整候选。内能检查同时覆盖守恒乘积和原物性核的动能计算顺序，
检查中间除法、乘法和求和有限。无负值截断、经验物理底限、自动降 dt
或调用邻点平均。theta=1 时跳过 RHS 修正，保留未激活 RHS 的位模式。
该充分预算可能在完整高阶更新仍有效时激活；其精度和耗散影响须单独验收。

通量凸混合思想参考 [Hu, Adams and Shu (2013), JCP 242, 169--180](https://doi.org/10.1016/j.jcp.2013.01.024)。
这里的完整 RHS、六面预算和 MPI 节点处理是本项目实现，不把该文的理想
气体 Euler 保正结论当作完整 Navier--Stokes 或边界处理的无条件保正证明。
独立边界滤波、吹吸壁面赋值与海绵步骤保持原实现，没有随之得到保正证明。
