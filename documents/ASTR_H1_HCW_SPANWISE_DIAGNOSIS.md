## 1. 结论与范围

对已有 Ma2 三维挤出斜激波红例，定位到激波传感器阈值触发的离散通量硬切换。
近顶面的光滑分支使用六阶通量候选，标记分支则返回旧二点中心／三阶近端模板，
并切入 Roe 特征空间。两套通量在传感器阈值处没有连续匹配。
微小展向差跨越阈值后，首先在顶面下一层产生有限的对流 RHS 差，再由 RK 更新放大。

这不是 GPU 独有的移植差异，CPU 同样复现；单 rank 也有相同的大放大响应。
但不能据此声称已经排除全部 MPI 误差、解释所有长期 HCW 扰动，或证明修订后一定稳定。
定位阶段未修改数值算法。随后获批的首个候选试接、短测与延窗反例见第8节，
其生产接线已经撤回；阈值、时间步、物理目标和滤波设置没有更改。

## 2. 实际回放设置与诊断量

来源为原均匀起算 Ma2 测试的 t=2 保存场：
`tests/gpu_validation/out/hcw_high_order_h1_20261027/euler_physical/` 下的
`test_uniform_start_generation0/gpu/outdat/new/checkpoints/step000000008000/state.h5`。

- 区间数192×192×8，x/y范围[0,1]，z范围[0,0.125]，周期重复的末端z节点不参与范数。
- gamma=1.4，Ma=2，激波角40度，顶面入射位置x=0.25。
- 743e/643e、MP7-LD，权重0.1，shkcrt=0.001；无黏、主滤波关闭、顶面横向滤波关闭。
- 边界11/22/421/52/1/1，`sbli_grcbc` 的 H1 完整 RHS；MP 保正关闭。
- dt=2.5e-4，128个完整步，观测窗0.032；NP=2采用2×1×1，另做NP=1对照。

将原场分为唯一展向节点的均值与扰动，保留扰动的1e-4或1e-6。
这只生成诊断初场，不是对生产状态平滑，也不是精确重启。
Python 不推进流场，所有步进与 RHS 均由实际 ASTR 可执行文件完成。

报告的“顶面三层L2”为五个守恒分量减去展向均值后的离散欧氏范数：

$$
\left[\sum_{i}\sum_{j=190}^{192}\sum_{k=0}^{7}\sum_{m=1}^{5}
 (q_{ijkm}-\overline q_{ijm})^2\right]^{1/2}.
$$

它不是体积加权物理能量或渐近增长率。RHS 数值除以笛卡尔 Jacobian
J=(1/192)^2(0.125/8)，对应dq/dt，未乘dt。
场序列中的q由正常输出的rho/u/p重建，定位阶段与最终对照则读取权威q快照。

## 3. 时间与阶段定位

当前程序再次得到原放大倍数73.4939634582和1.95536398384。
较大扰动并非从首步持续指数增长，而在后续阶段出现局部突增：

| 完整步 | 顶面三层L2 |
| --- | ---: |
| 0 | 3.1821443785e-6 |
| 96 | 2.5763240663e-6 |
| 120 | 5.7074233033e-6 |
| 124 | 2.2113604168e-4 |
| 128 | 2.3386840267e-4 |

在原红例的首步记为0的回放编号下，第123步第3个RK阶段，顶面三层掩码首次在
已抓取的120–124步窗口中出现展向分歧。位置集中在x索引66–75附近。
关键源点为(71,191)，原始传感器在不同z节点取
0.000999158478至0.001000545939，跨越0.001。
膨胀后的(72,191)掩码由全1变为`[0,1,1,0,0,0,0,0]`。

在(72,191)，阶段输入相对展向均值的最大q差仍只有1.27544e-6。
但该阶段能量RHS的展向极差达到0.510194；此前一个RK阶段仅6.89627e-5。
按实际方向快照分解，突增阶段的能量RHS极差为：

| 方向／增量 | 展向极差 |
| --- | ---: |
| x向对流 | 0.0389291 |
| y向对流 | 0.4712644 |
| z向对流 | 1.82337e-5 |
| 此内点的完整边界修正 | 0，逐值为零 |

极差不是可线性相加的收支项，但该分解明确显示y向为主要突增来源。
该处v约为-0.161，不是法向速度接近零的掠入分类点。
边界修正增量为零只排除本阶段在该内点直接施加特征修正的解释，
不排除顶面闭合对非均匀背景及前序扰动的间接影响。

## 4. 原生单rank阈值夹逼

从突增前同阶段的两个展向平面构造二维重复初场，保留x/y非均匀背景。
两份近邻初场在同一位置分别落在阈值两侧，CPU/GPU均以NP=1实际执行。
再沿这两平面的线性插值对传感器阈值作局部夹逼；只构造输入，不用Python计算时间推进。

| 量 | 阈值下侧 | 阈值上侧 |
| --- | ---: | ---: |
| GPU原始传感器，(71,191,0) | 0.000999999994487835 | 0.001000000005512309 |
| 目标掩码，(72,191,0) | 0 | 1 |
| GPU能量完整RHS，(72,191,0) | -0.624034588245383 | -0.107012495154796 |

两份阶段输入q的全场最大绝对差为1.0930589767e-10，能量RHS差仍为0.5170220931。
CPU得到相同掩码与0.5170220931的RHS差。
CPU/GPU输入最大缩放差1.36213e-15，完整dq/dt最大绝对差2.35013e-12。
这表明突增不能解释为随输入扰动连续缩小的纯线性放大，也不能解释为GPU或MPI独有错误。

原幅值的完整128步GPU回放，NP=1与NP=2的顶面三层L2分别为
2.3386840251e-4和2.3386840267e-4。
两者全场q最大差仍有1.09026e-6，因此本项不是多拓扑场差验收。
它只证明无需跨rank接口，也能产生相同量级的大放大。

## 5. 代码机制

原始传感器为Ducros因子乘压力曲率，膨胀邻域最大值与shkcrt作严格大于比较。
当前邻域为沿三轴的十个偏移构成的交叉，不是任意三维球状邻域。

- `src_gpu/shock_sensor_gpu.cuf::raw_shock_sensor_kernel/expand_shock_sensor_kernel`：
  连续传感器变为0/1掩码。CPU对应`src/commcal.F90::ducrossensor`。
- `src_gpu/solver_gpu.cuf::mp_ld_interface_flux`：物理边界近三界面仅在
  `.not.shock.and..not.hdiss`时使用`boundary_mp_flux6`；否则改走旧重构。
- `src_gpu/solver_gpu.cuf::reconstruct_mp_ld_stencil`：紧邻顶面的界面使用
  二点中心，再下一行使用SUW3，第三行使用MP5-LD。
- `src/solver.F90::convrsduwd/high_order_interface_flux_cpu`与
  `src/flux.F90::recons_exp`具有相同的模板分流。

因此，不只是某个连续MP限幅函数自身的导数不光滑，而是一个布尔掩码同时改变了
重构模板、近端阶数和物理／特征空间处理方式。
在同一非均匀背景，六阶候选与旧低阶模板本来就有有限通量差，阈值两侧没有连续匹配。
x方向在该位置不属于物理x端点，其较小跳变还涉及内部物理／特征分流，须单独处理。

## 6. 待批准的数值修订方向

建议先研究H1近端的统一高阶候选与连续限幅，取消传感器一跨阈值就替换整套
二阶／三阶模板的做法；不直接将无限制高阶候选用于激波。
同时将内部物理／特征分流列为独立对照，不能只消掉y向主要跳变就宣称完整修复。

本节是初次定位时提交的方向，用户随后批准试制；首个具体候选及否决结果见第8节。
不能把该授权或局部连续性通过当作完整数值方案已经验收。
具体候选须先检查常数保持、光滑精度、间断附近的有界性以及阈值两侧通量连续性，
再同步CPU/GPU、回放两种扰动、NP=1/2和原观测窗，并检查减步及更长窗口。
最后才判断是否重启HCW物理稳健性验证与统计收敛。
不通过改变shkcrt、增大耗散、开启顶面滤波、抹平z方向或选择一个有利dt来关闭问题。

### 8.2 延长窗口失败及先后顺序

## 9. 联合定位：四组原生对照

用户随后批准联合定位与数值设计。本轮增加仅在`ASTR_BUILD_TESTING`下可选的
`ASTR_VALIDATION_H1_VARIANT`，不设置时保持原H1；非测试构建中的候选标志为编译期false。
四个测试变体为`legacy/internal-only/near-only/both`，法向D6、外部参考、dt和初场均不变。
各变体分别使用原H1、h1i、h1n、h1c身份，不能跨变体作同算法精确续接。

225步原生GPU两因素对照完成。这里的失败轨迹是因果诊断，不是通过的验收项：

| 变体 | 是否完成225步 | 第224步归档顶面三层的平均密度最大值 |
| --- | --- | ---: |
| 原H1 | 是 | 1.504788 |
| 只改内部 | 是 | 1.504786 |
| 只改近端 | 否，非有限退出 | 14.328671 |
| 两者同时改 | 否，非有限退出 | 14.328944 |

只改近端也会使均值解失稳，而只改内部不会在本窗口产生同一失败。
密度峰在第48步已移到(50,191)，随后在顶面下一层增长并缓慢向下游移动。
这发生时展向扰动仍很小，不是“展向扰动先增长到大幅值，再把均值场破坏”的同一条链。
原H1和只改内部仍有展向增长，完成本窗口不记为稳健性通过。

首阶段同状态原生RHS对照中，输入q逐值相同；激波入口附近x索引40–64范围内，
顶面j=192的完整RHS逐值相同，j=187/188也相同。
内部三层j=189/190/191的dq/dt最大差分别8.97154、4.53092、3.52997。
局部最大差位于(50,189,0)的能量分量。
CPU/GPU只改近端的完整dq/dt最大差为2.37411e-12。

这把新失败的因果范围缩小到近端处理及其边界块配套，而不是独立的内部MP7或CUDA实现。
末次只用x向RHS即可产生负内能是当时坏状态的触发点，不能反向用来认定上游原因就是x向格式。
保留D6端点却改变内部三层的非线性通量，是否产生特定的不稳定模态，仍需联合分析证明。
