# HB6 近壁滤波与壁面投影相容设计

## 状态与范围

用户已批准开展相容闭合设计，但尚未批准具体新系数或生产接入。
本轮只有静态矩阵研究、实际Fortran过程提取及回归探针；没有修改求解器。
目前比较的四类候选均存在增长反例，不能推荐其中任一类直接接入。

保持hm=5、深内点十阶显式滤波、六阶导数、RK3及原壁面物理条件不变。
首轮考虑非反应FP64均匀笛卡尔的41/42/421壁面链；本次否决证据只需其42/421
静止基态下相同的法向块，不把该块对照称作完整五变量CFD或物理验证。
原hermite7主滤波准入继续关闭，单分量／全分量生产实现均未扩展。

设计依据为主计划D07、D08及实施状态第17节。
实际重复滤波可能破坏原离散的稳定性，单独滤波的谱半径不是充分条件。
Lundquist与Nordström给出的稳定滤波理论强调与空间离散共用内积的收缩性[^1]。
该理论有明确的半有界离散和内积前提，不能直接当成ASTR现有闭合的稳定性证明。

## 约束和组合

F0为实际CPU主滤波矩阵，P_N由七个内点恢复绝热端点温度，R选取内点。
C为两端h倍向内Neumann7导数，其单端八节点权重为：

```text
c = [-1089, 2940, -4410, 4900, -3675, 1764, -490, 60] / 420
C P_N = 0
```

C不是用于壁面诊断的匹配D6导数。第一stage先滤波、重建壁面，再保存qsave。
令A为原已批准壁面的冻结法向NS矩阵、B=I+dt*A、F为约化滤波矩阵，实际组合为：

```text
S1 = B F
S2 = 3/4 F + 1/4 B F S1
M  = 1/3 F + 2/3 B F S2
```

本轮不移动qsave，不更改滤波次数或RK组合，不用无滤波结果代替滤波验收。
原谱门槛及近单位特征值记录保留；特征对残差和条件数用来区分真实增长与数值不确定性，
不将“接近1”一律当通过。

## 四类候选及否决证据

### 温度状态的正交投影

先对滤波后的温度施加欧氏最小二乘投影，再恢复原约化变量：

```text
Q_T = I - C^T (C C^T)^(-1) C
F_T = R Q_T F0 P_N
```

密度、速度块不改变。这只是一种线性温度块设计试验，不是已经实现的非线性守恒能量更新。
虽然C*Q_T=0，联合映射仍可能增长，故不能仅凭温度约束得到恢复就采用。

### 仅约束滤波增量

J是端点为0、内点为1的对角选择矩阵。保持端点增量为零，将滤波增量投影到C的零空间：

```text
F_delta = F0 - J C^T (C J C^T)^(-1) C (F0 - I)
C F_delta = C
```

只在近端七个内点改变增量，深内点映射不变，仍不保证与原空间算子共用一个收缩内积。
该候选的联合增长比原候选更大，已否决。

### 八阶及十阶近端映射

对p=8或10定义向前p阶差分，r为从物理面向内的节点编号：

```text
Delta_p q = sum(j=0..p) (-1)^(p-j) binomial(p,j) q_j
F_p(q)_r = q_r + (-1)^(r+1) Delta_p q / 2^p, r=1,2,3,4
```

右侧采用镜像。端点恒等，r>=5的原深内点映射不变。
系数由保持0至p-1次多项式及消除交替节点模态确定，没有拟合物理算例或新增经验强度。
八阶候选只改变原前三个六阶近端行；十阶候选改变前四个近端行。
它们分别需要至少9、11个物理节点，本轮不为更短线静默切换其他算法。

精确有理数矩、端点／深内点逐值不变及内部交替模态消除检查通过。
32区间初查未见原1e-4量级增长，但扩展到12区间后均出现真实增长，不能据此准入。

## 独立CPU缺陷：8区间闭合重叠（已修复）

修复前实际提取 `src/filter.F90::spafilter10exp`，取ntype=4、dim=8和常数q=1：

```text
CPU result = [1, 1, 1, 1, 2, 1, 1, 1, 1]
```

左闭合在ii=4累加八阶滤波，右闭合又在ii=dim-4=4向同一个ff(ii)继续累加。
缺少重置导致中心行翻倍。这不是联合谱问题，也不是滤波理论允许的误差。

`src/comsolver.F90::filterq_explicit10` 在x/y/z调用该函数，调用点没有针对该重叠的处理。

### 小CFL增长的结构性诊断

上表的二进制分数反例采用参数对
(-1,-1)、(-1/2,1/2)、(1,-1)、(3/2,3/2)。这是已否决的诊断对象，不是实施候选。
8区间41模型的增长特征值约为0.99997042356+0.00794363338i，
特征对残差约5.68e-16、条件数约3.02，不能归为舍入。

将实际滤波RK映射按dt精确展开：

```text
M(dt) = M0 + dt M1 + dt^2 M2 + dt^3 M3
M0 = F/3 + F^2/2 + F^3/6
M1 = A F^2/2 + (A F^3 + F A F^2 + F^2 A F)/6
M2 = (A F A F^2 + A F^2 A F + F A F A F)/6
M3 = (A F)^3/6
```

令R、L为F的单位特征值左右子空间基，L^T R=I，P1=R L^T。
在该单位特征值半单且相关声学分支简单的情形，取：

```text
X  = (I - M0 + P1)^(-1) (I - P1) M1 R
S1 = L^T M1 R
S2 = L^T M2 R + L^T M1 X
lambda(dt) = 1 + lambda1 dt + lambda2 dt^2 + ...
```

lambda1为S1对应特征值，lambda2由该分支左右特征向量对S2求双线性商。
若lambda1=i*omega，则振幅和log振幅的二阶系数均为Re(lambda2)+omega^2/2。
该反例的单位子空间维数14，左右基残差均在约1.4e-15以内、交叉基条件数约3.64。
对应分支lambda1约为i*7.51977088，lambda2约为-26.47289703，
二阶振幅系数约+1.80058003。

| dt | 直接log振幅/dt^2 |
|---|---:|
| 1e-3 | 1.772526 |
| 5e-4 | 1.793538 |
| 2.5e-4 | 1.798818 |
| 1e-4 | 1.800298 |

直接矩阵结果趋近所推导的正系数，解释了稀疏CFL点通过但更小CFL仍失败的现象。
不是声称步长越小增长越快：该项每步为O(dt^2)，固定物理时长下相应增长率为O(dt)。
它仍不能满足本轮不增长的谱门槛，也不能以“减步后增长较慢”冒充稳定性通过。

实现为 `review_high_order_wall_filter_design.py::rk_filter_taylor`、
`slow_filter_coefficients` 和 `small_cfl_diagnostic`；
直接对照见 `hb6_symmetric_dyadic_review_20261028/small_cfl_diagnostic.json`。
无滤波极限及非对易矩阵展开已与原stage组合核对；非纯虚一阶系数的振幅公式另有单测，
其二阶项用Re(lambda2)+(Im(lambda1))^2/2，不混淆为log振幅通式。
`hb6_design_algebra_final_20261028.xml`的10项检查通过，只是代数和回归探针通过，不是候选稳定。

## 已批准A：扩展为分量耦合设计

目前研究族要求五个守恒分量共用同一套标量近端滤波，随后施加壁面投影。
它尚未形成通过全部已检查门槛的解；有限搜索失败不是不存在其他标量系数的证明。

建议允许研究**物理分量耦合的近壁滤波／投影**，将密度、法向动量及能量的配套关系纳入
共同离散内积或小步相容条件，而不是继续只优化单个标量滤波谱。

拟保留以下边界：非反应FP64首轮，深内点仍按各守恒分量使用原十阶显式映射；
hm=5、原物理壁面目标及壁面密度独立推进不变；不改RK存储相位、不引入隐式全局求解。

## 已批准A的研究结果与新的停止点（2026-10-29）

### 耦合坐标与局部参考

在均匀静止基态rho=R*T=1、gamma=1.4下，取r为密度扰动、theta为相对温度扰动：

```text
p' = r + theta
s' = theta - 0.4 r
delta = Fp - Fs
F_r,r     = Fs + delta/1.4
F_r,theta = delta/1.4
F_theta,r = 0.4 delta/1.4
F_theta,theta = Fs + 0.4 delta/1.4
```

法向速度另用Fv，温度仍按原Dirichlet或Neumann7状态投影。
相同Fp/Fs/Fv时逐值恢复原标量算法；端点密度、镜像、深内点及六阶多项式条件已核对。
这只是线性化候选，尚未定义非零背景速度下的完整非线性守恒能量实现。

直接拼接原近端六阶／八阶映射的8种组合均在扩展诊断中失败。
三模态连续混合的30代有界搜索也未通过，未据此宣称不存在其他耦合解。
源程序为 `test_high_order_coupled_filter_candidate.py`，数据分别在
`out/hb6_modal_filter_candidates_20261028` 和 `out/hb6_modal_blend_search_20261028`。
搜索中的复合目标不是谱半径，也不是放宽后的验收指标。

随后构造了有限小域的正定二次型与约束投影参考。它保持物理约束和多项式，
在该小域下可有收缩性质，但抽取近端行接到十阶内点后，16区间仍出现约1e-4增长。
多项式相容边界延拓参考也未通过所有有黏检查，不能转成生产闭合。
系数矩阵与反例保留在 `out/hb6_coupled_projection_reference_20261028`、
`out/hb6_coupled_embedded_review_20261028`、`out/hb6_polynomial_lift_reference_20261028`。

这些参考不是“自写新求解器”：只构造有限线性算子和RK映射，没有Python流动推进。
嵌入试验将前7内点暂视为近端条带，原第5至7行也会改变；它不是已批准的实现。
9至15区间的条带重叠及小局部分区的共享节点所有权尚未解决，没有因此更改尺寸准入或MPI规则。
当前测试驱动在参考失败后停止其后续嵌入，见 `out/hb6_polynomial_lift_gated_20261028`。

### 新发现：无滤波的短物理域有黏失稳

构造有黏参考时发现，其所需的稳定空间算子前提并不总成立。
现有Neumann7绝热高阶法向模型在**整个物理法向域**只有8或9区间时，加入黏性后出现正实部。
它不是“大域被分成每rank局部8区间”，也不能据此判定原多rank结果失败。

| 全局法向区间 | nu | 最大特征值实部 | 证据性质 |
|---:|---:|---:|---|
| 8 | 0 | 约2.6e-15 | 原冻结无黏模型，舍入范围 |
| 8 | 1e-5 | 约3.41313e-4 | 原冻结有黏模型，明确增长 |
| 8 | 1/1600 | 约2.13025e-2 | 原冻结有黏模型，明确增长 |
| 9 | 1/1600 | 约1.11182e-2 | 原冻结有黏模型，尚未做原生9区间探针 |
| 10/11/12/14/16/20/24/28/32/64/128 | 1/1600 | 本组在舍入范围内 | 有限采样，不定义通用最小尺寸或黏性范围 |

无黏、法向黏性、热扩散三个算子分别没有同样的正谱，不代表相加后仍稳定。
在8区间的i*24.55161409模态上，对nu的一阶特征值漂移为：

```text
d lambda/d nu = (left^H D right) / (left^H right)
momentum-viscous contribution = +18.91156272
thermal contribution          = +15.21975578
sum                          = +34.13131850
```

这里是离散特征值扰动，不是物理能量收支。结果指向无黏与黏性壁面闭合的配套问题，
尚未证明某一个近端行或物理边界条件是唯一根因。
完整数据与生成函数见 `test_high_order_short_line_diagnosis.py::frozen_short_line_report`
及 `out/hb6_unfiltered_short_line_operator_20261028/report.json`。
421在静止基态共享这个法向模型；随后新增的原生421探针也重现同一增长，见下文补充。

### 实际ASTR RHS已重现

原生诊断使用根CMake的FP64/CUDA可执行文件，8×8×8、NP=1、y两端42、x/z周期，
643e/643e、RK3，关闭主滤波、驱动力及原位渲染。

Sutherland给出基态nu约3.9502452e-5。人工基态只用于RHS雅可比诊断，不是物理算例验证。
