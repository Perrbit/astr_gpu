## 约束和组合

F0为实际CPU主滤波矩阵，P_N由七个内点恢复绝热端点温度，R选取内点。
C为两端h倍向内Neumann7导数，其单端八节点权重为：

```text
c = [-1089, 2940, -4410, 4900, -3675, 1764, -490, 60] / 420
C P_N = 0
```

C不是用于壁面诊断的匹配D6导数。第一stage先滤波、重建壁面，再保存qsave。
令A为原已批准壁面的冻结法向NS矩阵、B=I+dt*A、F为约化滤波矩阵，实际组合为：

```text
S1 = B F
S2 = 3/4 F + 1/4 B F S1
M  = 1/3 F + 2/3 B F S2
```

本轮不移动qsave，不更改滤波次数或RK组合，不用无滤波结果代替滤波验收。
原谱门槛及近单位特征值记录保留；特征对残差和条件数用来区分真实增长与数值不确定性，
不将“接近1”一律当通过。

## 四类候选及否决证据

### 温度状态的正交投影

先对滤波后的温度施加欧氏最小二乘投影，再恢复原约化变量：

```text
Q_T = I - C^T (C C^T)^(-1) C
F_T = R Q_T F0 P_N
```

密度、速度块不改变。这只是一种线性温度块设计试验，不是已经实现的非线性守恒能量更新。
虽然C*Q_T=0，联合映射仍可能增长，故不能仅凭温度约束得到恢复就采用。

### 仅约束滤波增量

J是端点为0、内点为1的对角选择矩阵。保持端点增量为零，将滤波增量投影到C的零空间：

```text
F_delta = F0 - J C^T (C J C^T)^(-1) C (F0 - I)
C F_delta = C
```

只在近端七个内点改变增量，深内点映射不变，仍不保证与原空间算子共用一个收缩内积。
该候选的联合增长比原候选更大，已否决。

### 八阶及十阶近端映射

对p=8或10定义向前p阶差分，r为从物理面向内的节点编号：

```text
Delta_p q = sum(j=0..p) (-1)^(p-j) binomial(p,j) q_j
F_p(q)_r = q_r + (-1)^(r+1) Delta_p q / 2^p, r=1,2,3,4
```

右侧采用镜像。端点恒等，r>=5的原深内点映射不变。
系数由保持0至p-1次多项式及消除交替节点模态确定，没有拟合物理算例或新增经验强度。
八阶候选只改变原前三个六阶近端行；十阶候选改变前四个近端行。
它们分别需要至少9、11个物理节点，本轮不为更短线静默切换其他算法。

精确有理数矩、端点／深内点逐值不变及内部交替模态消除检查通过。
32区间初查未见原1e-4量级增长，但扩展到12区间后均出现真实增长，不能据此准入。

### 小CFL增长的结构性诊断

上表的二进制分数反例采用参数对
(-1,-1)、(-1/2,1/2)、(1,-1)、(3/2,3/2)。这是已否决的诊断对象，不是实施候选。
8区间41模型的增长特征值约为0.99997042356+0.00794363338i，
特征对残差约5.68e-16、条件数约3.02，不能归为舍入。

将实际滤波RK映射按dt精确展开：

```text
M(dt) = M0 + dt M1 + dt^2 M2 + dt^3 M3
M0 = F/3 + F^2/2 + F^3/6
M1 = A F^2/2 + (A F^3 + F A F^2 + F^2 A F)/6
M2 = (A F A F^2 + A F^2 A F + F A F A F)/6
M3 = (A F)^3/6
```

令R、L为F的单位特征值左右子空间基，L^T R=I，P1=R L^T。
在该单位特征值半单且相关声学分支简单的情形，取：

```text
X  = (I - M0 + P1)^(-1) (I - P1) M1 R
S1 = L^T M1 R
S2 = L^T M2 R + L^T M1 X
lambda(dt) = 1 + lambda1 dt + lambda2 dt^2 + ...
```

lambda1为S1对应特征值，lambda2由该分支左右特征向量对S2求双线性商。
若lambda1=i*omega，则振幅和log振幅的二阶系数均为Re(lambda2)+omega^2/2。
该反例的单位子空间维数14，左右基残差均在约1.4e-15以内、交叉基条件数约3.64。
对应分支lambda1约为i*7.51977088，lambda2约为-26.47289703，
二阶振幅系数约+1.80058003。

| dt | 直接log振幅/dt^2 |
|---|---:|
| 1e-3 | 1.772526 |
| 5e-4 | 1.793538 |
| 2.5e-4 | 1.798818 |
| 1e-4 | 1.800298 |

直接矩阵结果趋近所推导的正系数，解释了稀疏CFL点通过但更小CFL仍失败的现象。
不是声称步长越小增长越快：该项每步为O(dt^2)，固定物理时长下相应增长率为O(dt)。
它仍不能满足本轮不增长的谱门槛，也不能以“减步后增长较慢”冒充稳定性通过。

实现为 `review_high_order_wall_filter_design.py::rk_filter_taylor`、
`slow_filter_coefficients` 和 `small_cfl_diagnostic`；

### 新的声学交叉族：代数成立但联合谱失败

在已批准的静止基态`rho=R*T=1`下，取`p'=r+theta`、`s'=theta-0.4r`、`a=sqrt(1.4)`。
允许正反声学分量`p'+a*v`与`p'-a*v`具有不同近壁映射，得到：

```text
p_new = F_a p + a K v
v_new = F_a v + K p / a
s_new = F_s s
r_new = (p_new-s_new)/1.4
theta_new = (0.4*p_new+s_new)/1.4
```

`F_a/F_s`只调整原前四个内点的滤波增量，深内点仍为原十阶映射。
`K`在下端取原增量、上端取负镜像，物理端点为零。
N8共享中心行的`K`取零以保持反射奇偶性，不把同一节点重复写两次。
声学平均强度取1/8、1/4、1/2、3/4；熵强度取1/8、1/2、1；
交叉强度取正负`min(acoustic_strength,1-acoustic_strength)`和0，其中`acoustic_strength`为上述声学滤波强度。
这些是研究参数网格，不是经验生产系数、优化结果或新增运行选项。

## 共同内积的精确障碍及H(nu)参考（2026-10-30）

### 不能把浮点小特征值当作不存在性证明

初步浮点约束分析中，42的必要内积矩阵族出现非常小的公共平方和特征值。
精确有理数核查表明，N8/9的公共核维数均为0，不能据浮点截断宣称所有内积都奇异。
真正的障碍来自下述不定子空间，而非该浮点秩判断。

`review_high_order_common_metric.py`用原已批准的P6/T7及41 P7系数建立精确矩阵，
不依赖优化器给出的不可行标志、不引入奇异值截断或替换原空间块。
与现有浮点模型的差异只在原舍入参照内，模型本身的原生RHS验证仍见第24节实施状态。

### 一份固定内积不能同时适配当前42/421的无黏与有黏块

考察当前静止、均匀基态法向块，记`qdot=(A0+nu*D)q`。
若一份与nu无关的H正定且使无黏和有黏算子都半有界，
由于`trace(A0)=0`，有：

```text
A0^T H + H A0 = 0
D^T H + H D <= 0
```

理由是第一式左端经H的平方根合同后半负定且迹为0，因此只能为零。
这不是要求所有可能的滤波方法必须存在这样一份H，只是所研究共同内积路线的必要条件。

D的密度列为零。上述半负定矩阵的密度对角块因此为零，对应整行/列必须为零。
结合实际G和法向黏性Dv满秩，任意可行H必须具有：

```text
H = [ H_r   0    X  ]
    [  0   H_v   0  ]
    [ X^T   0   H_T ]
X D_T = 0
```

这里r为密度扰动、v为法向速度、T为相对温度扰动，三者沿用前节基态归一化。
精确程序穷尽这一必要线性解空间，而非只挑一份特征向量内积。
N8与N9的解空间维数分别为10、9；不正定的矩阵也保留在其中，没有先作正定筛选。

取法向速度的**节点反序对称子空间**，即`v_i=v_(N-i)`，以S为其基。
精确计算发现该子空间中所有限制矩阵都只能写成：

```text
S^T H_v S = alpha C
```

这指矩阵族只有一个自由尺度，不是说4×4模板C的矩阵秩为1。
N8的C同时有严格正、负对角元；N9的一个2×2主子式行列式严格为负。
因此C不定，非零alpha不可能使其正定，alpha=0也不正定。
若H正定，其任意满列秩子空间限制应正定，与此矛盾。
完整模板、有理数正负二次型见证、线性空间维数和逐项等式检查均保存在
`out/hb6_exact_common_metric_certificate_20261030/N8_bc42.json`及`N9_bc42.json`。
这也是421共享法向块的结论，不扩大为所有边界和网格的定理。

41 P7的同类限制没有上述不定性见证；程序报告“尚未证明正定/黏性耗散”，
不把42结论套给41，更不将未发现障碍说成已经找到了完整可行内积。

### 该障碍不等于有黏算子不稳定

它只排除了当前小域模型中一份固定H同时覆盖nu=0和正nu的强要求。
允许H依赖nu时，可以按完整有黏算子`A(nu)`构造诊断参考。
本轮N8/9、41/42、nu=0/1e-5/1/1600的12份匹配参考，
在已列小CFL样本中都未触发谱失败，并核对了正定性、生成元能量残差、滤波收缩及端点/多项式残差。
原来使用同一无黏H检查正nu的反例继续保留，不改成通过。
证据为`out/hb6_matched_metric_reference_20261030`。

这些仍是稠密全局小域投影，没有局部性和深内点十阶保持证据。
即使保持五次多项式，也不能据全域固定次数投影推断随网格加密具有六阶局部残差。
因此没有把它们转成生产系数或声称HB6通过。

### 端点对偶不变量排除了当前参考的直接局部化

若滤波F在H内积收缩，并严格保留端点密度的线性泛函E，则还必须满足：

```text
E^T F = E^T  and  F^T H F <= H
                 => F H^(-1) E = H^(-1) E
```

也就是说，`H^(-1)E`不能仅被当成任意参考向量，它必须是F的固定向量。
若只允许改近壁若干输出行，这个恒等式在保留原十阶映射的深内点行已经不能成立，
那么该H不可能直接配成满足全部要求的局部滤波。

### 正式参考与非线性守恒量作用

按用户批准复用`test_high_order_wall_runtime.py::initial_fields(manufactured=True)`：
密度`1+.01cos(pi*y)`，温度`1+.02sin(pi*y)^2`，速度及421滑移变体沿用该函数。

所有五个守恒分量均非零变化，额外`rho=p/T`场及其低观测阶作为补充诊断完整保留。
正式参考的密度六阶首项严格非零；N64八阶项相对六阶项小于0.1，不存在原场的强抵消。

候选直接对`rho,rho*u,rho*v,rho*w,rho*E`使用同一个标量映射。
没有先滤原始变量再重建全域守恒量，也没有为压力/熵另加权。
同一方向的全部分量完成后再恢复所需物性；整个方向序列完成后按原阶段位置恢复壁面状态：

1. 法向滤波不改壁面rho；不从外推压力或给定温度反算rho。
2. 保持41/42无滑移、421滑移及对应温度条件，沿原高阶闭合重建受约束的壁面速度/温度。
3. 只用当前rho、当前受约束速度和温度更新壁面动量/能量及EOS缓存。
4. 继续原halo/共享节点及物性刷新，不在分量循环中途做跨分量的热力学重建。
5. 首stage的qsave仍在首次滤波/壁面恢复后的状态保存，后续stage照原滤波与RK3组合。

该映射作用于守恒变量不等于其全域加权积分严格守恒；常数保持也不等于列和保持。
它不保证一般非线性状态保正。后续必须分别记录滤波增量、壁面恢复增量和推进收支，
不能把crashfix后跑完或单次正值误认为保正证明。
正式单次参考中rho最小0.99，T最小约0.99999977，法向壁面速度及壁面rho变化均为零。
42/421记录的热条件残差为`h*dT/dn_N7`，41为`T-Twall`；80位算术残差至多约5.54e-81，

### 近壁重叠及MPI归属

沿法向的物理面只拥有其前四个输出行，不能因某个内部rank局部下标为1就套物理闭合。
每行读取从该物理面向内的0至8节点；rank内部界面仍用原十阶中心映射和hm层halo。
对滤波取数本身，边界rank有7个局部区间时，第8节点只需一个朝内MPI halo，不要求扩大hm。
这不替代已有整链准入：41原允许局部7区间，42/421原要求局部至少8区间，
`validate_high_order_wall_geometry`的该限制本轮保持不变。前文索引证明不等于42/421的7区间运行准入。
共享节点的两个副本使用同一前方向状态和同一全局行；滤波通信只刷新halo，
不新增共享节点平均，也不把物理外侧无效ghost作为输入。

N8同一中心由两面条带覆盖，第4行对称使两种定义严格相同，只求值一次，禁止累加两次。
N9的第4/5行分别归属两面，其输入条带可重叠，但不重写同一输出。
精确代数检查包含N8/9单rank、N14按7+7分区、N16按8+8分区及N32/64四分区；
全局行、共享节点和可用hm=5数据严格一致。它们是索引证明，不是已运行的MPI通信测试。

### scalar/full数据依赖与代价

保持`ASTR_GPU_FILTER_WORKSPACE=scalar|full`，不增加第三种存储模式。
现有full路径为`q -> qwork(x) -> q(y) -> qwork(z) -> q`；
scalar逐分量执行相同x/y/z顺序，复用`filter_work_d`及原组件halo交换。
由于候选不在分量之间耦合，分量循环与各轴线性映射可交换；
壁面EOS重建必须等全部分量完成，不允许据此在分量循环中提前重建温度。
精确有理数多分量测试确认该代数等价，实际CPU/GPU舍入和通信仍待接线后验证。

令H为已有含halo本地节点数，FP64下full原工作区为`8*5*H`字节，scalar为`8*H`字节。
候选不改变这两个数组大小或原打包缓冲；两组4×9系数即使完整存储也仅576字节/后端。
边界每面每分量从原7+7+7+9个支撑读取变为4×9，最多增加6次标量读取；
两面五分量合计每法向线最多增加480字节逻辑读取，缓存复用另计。
深内点、通信层数和通信字节不变。不据此声称GPU已加速或没有寄存器代价。
分数仅用于初始化编译期FP64常数，不在每线程运行时做固定参数除法。
建议共享求值过程使用`q_r + sum(j!=r) w_j*(q_j-q_r)`的增量形式，
其中`w_j`为上述精确九权重的非对角项，按同一固定顺序求和。
这在数学上是同一映射，并使相等输入的增量严格为零；不是更换系数或消除全部舍入误差。
CPU/GPU实际矩阵、常数保持和近单位模态仍必须按编译后求值顺序重验，
不能直接把本轮有理数模型与宿主矩阵证据当成GPU核的实测结果。
