# ASTR GPU 验证结果摘要

验证日期：2026-09-29。以下记录针对本交付版本对应的非反应流实现。
基础配置为 FP64、explicit 同步、pinned 主机中转及 scalar 滤波工作区。
AIR5 不由本表放行。网格尺寸沿用输入 ia/ja/ka 约定，含端点存储尺寸可能多一。

## 构建与部署检查

验证环境使用 NVHPC 26.1、配套 HPC-X 2.25.1 和 HDF5 1.14.6。
CPU/CUDA 非反应流分别在不含 tests/ 的源码副本中完成构建、安装和运行。
已检查安装前缀覆盖、默认安装位置、二维与三维 TGV 输入分离及安装不修改源码。
安装版程序没有缺失动态库，且使用安装版实际完成下列代表性计算。

配置检查 7 项通过，CPU/CUDA 构建安装检查 2 项通过；
启动模板及相关输入、滤波配置检查 31 项通过。
这些检查不构成其他编译器、MPI、驱动或硬件组合的准入结论。

## 场与重启比较

| 算例 | 设置 | 结果 |
|---|---|---|
| TGV | 32³，NP2，2×1×1，100 步 | CPU/GPU 最大场差 4.831690603168681e-13 |
| TGV | 同上，full/scalar 对照 | 最大场差 0 |
| TGV | 同上，第 50 步恢复至第 100 步 | 与连续计算最大场差 0 |
| 槽道流 | 32³，NP2，2×1×1，固定驱动力，黏性与滤波开启 | full 与 scalar 连续计算场一致 |
| 槽道流 | 同上，第 50 步恢复至第 100 步 | 场差及对应步号统计差均为 0 |
| 静态曲线平板 | 64×64×16，NP2，1×2×1，100 步 | full/scalar 连续场一致；第 50 步恢复后的场及统计差为 0 |
| 固定 OpenSBLI 层流配置 | CPU NP1、GPU NP2，连续 4 步及 2→4 步 | 各自连续/恢复最大场差分别为 1.33e-15、2.22e-16 |
| 槽道序列输出 | NP2，连续 4 步及 2→4 步 | 序列恢复成功，最终场差 0 |

场比较涵盖已输出的密度、速度、压力、温度及由它们重构的五个守恒分量。
不同物理量的绝对误差使用各自算例单位，不能解释为统一量纲的物理误差。
滤波重启比较采用绝对阈值 1e-10，未通过放宽阈值获得上述结果。
TGV 的 CPU/GPU 比较采用绝对与相对阈值各 1e-10。

槽道流重启会重建文本统计记录，平板路径可追加记录。比较按实际步号对齐，
不把不同长度的文件直接逐行相减。新 GPU 恢复文件保存实际推进状态，而非
仅由已经过边界处理的展示场重建，从而保持下一步滤波输入一致。

## 恢复文件异常处理

以下 9 类异常均被拒绝：缺少某 rank 文件、存在未完成 .tmp、负载截断、
非有限值、生成代次不匹配、拓扑元数据不匹配、负载超长、未知版本、备份失败。
无新版本标识的旧文件仍可读取，但明确警告不能保证精确续算。
上述异常检查不等同于对文件任意位损坏均有校验和检测。

## 适用边界

- 上述短窗用于构建、数值一致和恢复验证，不证明长时统计收敛或实验符合性。
- 不覆盖任意边界方向、跨拓扑恢复、全部混合精度和 CUDA-aware MPI 组合。
- 不包含本交付版本在接收方目标平台上的性能承诺。
- AIR5 长时反应 SBLI、湍流入口收敛和外部数据库级验证仍需独立完成。
- 本文件仅提供公开验证摘要；部署方应保留自己的输入、日志与比较结果。
