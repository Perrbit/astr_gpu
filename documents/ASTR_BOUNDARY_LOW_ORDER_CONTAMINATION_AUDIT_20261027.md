# ASTR CPU/GPU 边界低阶误差来源审查

日期：2026-10-27。工作分支：`feature/gpu_dev`。
审查时 HEAD：`be5f8934bfc4e4346ca713f86b317bee58827dde`。
对象是当前工作区，包含尚未提交的 GRCBC v2 等改动，不代表上述提交已包含全部实现。
本记录只存档排查结果，不授权修改数值格式、物理边界或启动生产算例。

## 1. 结论与证据范围

主要低阶来源不仅在 bc52，还包括 MP7/MP7-LD 近物理边界的重构过渡、
近壁黏性梯度、NSCBC 法向导数、壁面状态重建、紧致导数端点及边界滤波。
优先排查 MP7 近端过渡、NSCBC 面内对流和近壁黏性梯度。

本轮完成源码检查和有理数多项式核验，没有新增 CFD 运行、修改源码或暂存/提交文件。
覆盖已实现 GPU 主边界家族、对应 CPU 公共算子及 AIR5 专用边界；
未对用户自定义边界、浸入边界和所有旧 CPU 专用算例作完整审计。

证据分为三类：

| 标记 | 含义 | 不能据此推出的结论 |
|---|---|---|
| 已确认模板 | 源码与系数矩检查支持所列局部阶数 | 不直接证明整个求解器同阶收敛 |
| 条件性风险 | 影响取决于边界假设、限制器激活或实际读取的 halo | 不等于当前算例已受污染 |
| 已观察场偏差 | 既有保存场存在可量化偏差 | 未作单因素对照前，不唯一归因于某个低阶模板 |

低阶边界闭合不自动等于 BUG。局部截断阶与全局收敛阶之间还取决于稳定性、
边界条件、方程和评价范数；不能把线性稳定格式的结论直接套用到当前非线性激波路径。[^accuracy]
下文阶数均针对光滑场及对应坐标中的局部离散。激波处不适用光滑 Taylor 展开。

## 3. MP7 近端过渡的一阶局部误差

在单向线性通量、采用当前物理端点模板的极限下，最靠近边界的两个数值界面通量为

$$
\widehat F_{1/2}=\frac{F_0+F_1}{2},\qquad
\widehat F_{3/2}=\frac{-F_0+5F_1+2F_2}{6}.
$$

对应实现是 `recons_exp/reconstruct_mp_ld_stencil` 的前两个物理界面分支，
三阶系数来自 `src/flux.F90::suw3` 和 `src_gpu/solver_gpu.cuf::suw3_gpu`。
这是数值通量差的代数检查，不把数值界面通量直接解释为物理半节点通量值。

在第一内点、均匀间距 h 下，正的通量导数为

$$
D F_1=\frac{\widehat F_{3/2}-\widehat F_{1/2}}{h}
=\frac{-2F_0+F_1+F_2}{3h}
=F'(x_1)-\frac{h}{6}F''(x_1)+O(h^2).
$$

因此局部首项误差是一阶。实际对流 RHS 使用负散度，误差符号相反但阶数不变。
取 F(x)=x²、x0=0、x1=h，当前模板给出的导数误差为 −h/3。
本轮用 Python 标准库 `fractions.Fraction` 按源码系数作精确有理数核验：

| h | 导数误差 | 误差/h |
|---:|---:|---:|
| 1/16 | −0.0208333333333 | −1/3 |
| 1/32 | −0.0104166666667 | −1/3 |
| 1/64 | −0.00520833333333 | −1/3 |

该核验不是新 CFD 算例，也没有包含有限幅 Euler 特征变化和 MP 非线性限制。
它证明近端混合通量存在一阶局部误差来源，不证明当前完整 SBLI 解只有一阶。
不同界面模板的误差项不能仅凭各自名义重构阶数认定在相减时会抵消。

## 4. 零梯度重建与几何假设

`extrapolate_2o(...,dv=0)` 与 GPU `extrap2` 的共同形式为

$$
f_0^{\mathrm{bc}}=\frac{4f_1-f_2}{3}.
$$

它来自三点二阶零导数条件，并非一般线性外推。对均匀坐标间距展开，

$$
f_0^{\mathrm{bc}}-f(0)=\frac{2h}{3}f'(0)-\frac{2h^3}{9}f'''(0)+O(h^4).
$$

当真实 f'(0)=0 时，重建边界值的误差可为 O(h³)，不能笼统说边界值只有二阶。
若真实 f'(0) 非零，则存在 O(h) 的局部重建偏差；更根本的问题是所施加边界条件可能不适合该工况，
不能由此直接推断整个解的收敛阶。

需要分别检查壁面压力、绝热壁温度、滑移速度以及普通外流状态。
吹吸、强曲率和明显法向流动下，不应未经法向动量/能量平衡检查就认定所有量均满足零法向梯度。
曲线网格中，沿逻辑网格线的零导数也不一定等于真实物理法向零导数；
对速度作几何投影，不自动解决压力、温度重建的这一对应关系。
这些是条件性风险，不表示本轮已证明所有壁面条件有物理错误。

## 5. AIR5 需要单列的处理

1. `air5_top_normal_convection` 使用三点二阶法向导数，`first_order=t` 时切换两点一阶基准。限制器未激活和激活时的实际精度必须分开判断。
2. `build_air5_hbl_wall_state` 的 `y_wall=y_one` 是第一内点复制，没有使用第二内点构造更高阶组分状态。应检查其与近壁输运模板的一致性，但不能直接认定存在非催化壁面组分泄漏。
3. CPU `src/chemistry_solver.F90:2173` 和 GPU `src_gpu/chemistry_solver_gpu.cuf:2728` 已在相应 HBL/SBLI 底壁显式将法向组分梯度置零，组分扩散通量应结合该路径判断。
4. `apply_air5_hbl_boundary` 对部分物理 halo 使用常值状态。只有消费这些 halo 的模板才受其外延精度影响；使用专门物理端点模板时不能自动判为一阶。
5. 该特征顶面目前有均匀笛卡尔网格准入检查，见 `src/chemistry_boundary.F90:284`。固定三点系数除以最外一层物理间距在一般非均匀网格上有降阶风险，但不能将其列为当前已准入非均匀算例的实证缺陷。

入口数据还有独立分辨率因素：`sample_air5_hbl_profile` 在非节点位置使用分段线性插值，
见 `src/chemistry_boundary_state.F90:268`。若原剖面采样不随网格加密，边界输入误差可能先达到平台，
不能将其误认为内部格式没有收敛。普通动态入口的三次插值不属于同一种处理。

## 6. 其他风险与不应误报的项目

### 6.1 几何 halo 的可疑索引

`src/bc.F90::geombc` 在上侧 bc41 的 i 循环中使用

```fortran
jacob(1,jm+1:jm+4,k) = gradextrp(qbou=jacob(i,jm,k), q1st=jacob(i,jm-1,k))
```

写入下标固定为1，而右侧和其他度量分量均随i变化。这是需要单独核查的 CPU 索引问题，
不是正常降阶。必须先确认当前消费路径是否读取这些外部 Jacobian，才能判断对已运行算例的影响。
本轮未修复或将其认定为既有场误差的原因。

`geombc/xyzbc` 还调用只由边界值和第一内点确定的 `gradextrp`；
高阶表达式的外观不代表输入包含了高阶几何信息。若后续完整 halo 模板读取该外延，需单独核对其精度。

### 6.2 边角交线

不能将面上的高阶处理直接外推为高阶交线处理。普通 `boucon` 按面依次处理，
具体组合需要唯一的状态/RHS所有者及兼容条件。
当前 GRCBC 上入口交线由完整入口状态负责，上出口交线要求流向超声速出流；
未实现的一般亚声速双面兼容会报告 status=4，而不是已被允许运行的低阶闭合。
`corner4nscbc` 本轮只找到定义，没有找到调用，不能把其代码作为当前运行污染证据。

### 6.3 滤波、MPI 与后处理的区别

- 主十阶显式滤波的物理边界节点保持原值，近端采用六阶、八阶过渡，再进入十阶。代码中的“0-6-6-6-8-10”首项表示不滤波，不表示零阶近似错误，见 `src/filter.F90::spafilter10exp`。
- NSCBC 自带六阶滤波与主滤波独立。`lfilter=f` 不一定关闭前者；GRCBC 顶面有明确的跳过分支，见 `src_gpu/boundary_gpu.cuf:1996`。
- MPI 接口不是物理边界。不能把物理边界的降阶条带计入每一个 rank 接缝；应核对 npdc、halo 和紧致跨 rank 耦合后再判断。
- 纯周期 TGV 不触发上述物理端点模板，不代表其实现可验证所有物理边界精度。
- 部分壁面后处理使用三点二阶导数，如 `src_gpu/insitu_wall_fields_gpu.cuf::derive_channel_wall_fields`。它可能限制输出剪切/热流的诊断精度，但不回写权威场，不是推进污染。

## 7. 与既有斜激波失败的关系

既有 GRCBC v2 的解析初场最细网格通过了角度/平台量门槛，
但均匀初场的192²×8、8000步、t=2验证未通过1%平台状态门槛：

| 指标 | 既有观察 |
|---|---:|
| 激波角误差 | 0.0303613° |
| 波后密度最大相对差 | 1.380719% |
| 波后温度最大相对差 | 1.315948% |
| 波后压力最大相对差 | 0.630553% |
| 顶面上游x=0.203125处密度 | 0.89293126，理论上游为1 |

密度误差峰值位于域内且远离激波核心，说明不能仅检查角度或压力跳跃。
这些数据没有唯一证明 B01、B02 或 B05 中哪一项是主要来源。
后续应使用相同状态和边界目标作单因素 RHS 对照，再判断是否需要替换模板。

公式、完整参数及原始失败证据见
[入射激波专项设计第10节](ASTR_NSCBC_INCIDENT_SHOCK_TOP_DESIGN.md#10-无黏斜激波与v2修订)。
原始场与诊断位于 `tests/gpu_validation/out/grcbc_oblique_v2_20261027_uniform/`，
本次存档没有重新生成这些场。
