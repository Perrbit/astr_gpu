## TGV Filter Policy

Path A sets `lfilter=f` in both CPU and GPU runs. It validates the minimum RHS/RK/updatefvar loop.

Path B sets `lfilter=t` in both CPU and GPU runs. It validates the default TGV path after explicit GPU filter is implemented.

## Runtime Input Line Ending Policy

Runtime input files under `examples/**/datin` must use LF line endings. CRLF can make NVHPC preserve `\r` in list-directed string tokens such as `flowtype`, which breaks `select case(trim(flowtype))`.
