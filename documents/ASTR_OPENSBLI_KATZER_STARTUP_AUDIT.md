## 2. 已锁定的几何与参考量

| 长度基准 | 入口可压缩位移厚度 delta_star_0 | 论文 / 入口积分交叉检查 |
| Reynolds 数 | Re_delta_star_0=950 | 数据 README |
| gamma | 1.4 | 示例源码及能量重构 |
| 温度基准 | T_inf=288 K | 论文 / 源码 |
| Sutherland 常数 | 110.4 K | 论文 / 源码 |
| 壁温 | T_wall/T_inf=1.676194 | HDF5 重构 |
| 物理网格点数 | Nx=609，Ny=255 | HDF5 属性 |
| x 网格 | 均匀，dx=400/608 | HDF5 |
| y 网格 | y=115*sinh(5*eta)/sinh(5)，eta=j/254 | 论文 / HDF5 |
| 顶面状态分界 | x>40 为激波后状态，其他为激波前状态 | 源码 / HDF5 |
| 标称激波倾角 | 32.58 度 | README |

采用 rho_inf=U_inf=T_inf=1，p_inf=1/(gamma*M_inf^2)。
由守恒量恢复 p=(gamma-1)*(rhoE-(rhou^2+rhov^2)/(2*rho))，
T=gamma*M_inf^2*p/rho。压力比 p3/p1=1.4 是完整干扰后的出口与入口之比，
不是一次入射激波的跳跃压力比，不可用来直接构造顶面单次激波状态。

不能把原 ASTR 的 REYNOLDS=296000 搬入本算例。
论文的入射站 Re_x=3e5 与入口 Re_delta_star=950 使用不同长度，须结合虚拟前缘换算。
ASTR 输入中的 IM/JM 与物理点数还须按生成器端点规则核对，不能未经检查直接填 609/255。

## 3. 初始条件

论文 3.3.7 明确：将同一个入口相似解剖面沿整个 x 方向铺开，随后由时间推进形成空间发展。
不是全域均匀自由流，也不是沿 x 按不同发展距离生成的相似解族。
参考初始化不需要预先在全场叠加斜激波，激波由顶面边界产生。

入口包含 rho(y)、u(y)、v(y)、T(y)，其中 rho=1/T，v 由连续性关系求得。
相似解使用绝热条件确定恢复壁温，正式二维 SBLI 计算则使用这一温度的等温壁面。
不能据此把 SBLI 的壁面改为零热流边界。

后续源码将相似解作多项式拟合；入口/初值匹配需量化拟合和插值误差。
当前 ASTR `generate_compressible_blasius_profile.py::write_similarity_initial_field`
使用随 x 发展的相似解场，不符合上述初值语义。
其 `solve_profile` 可作为数学实现参考，但应先校准 delta_star=1、法向速度和温度剖面。
归档 HDF5 是 t=13000 的结果，不能直接当作独立验证的全场初值。
其中入口剖面可用于检查生成结果；若作为参考驱动入口使用，必须另行标注验证范围。

## 4. 四面边界合同

| 面 | OpenSBLI | 当前 ASTR SBLI | 结论 |
|---|---|---|---|
| x- | 相似解入口，按局部声速区分超/亚声速，亚声速区压力外推 | bctype=11 强制给定 rho/u/v/w/p/T | 不等价 |
| x+ | 守恒量从最后内部点向边界和 halo 做零阶外推 | bctype=21；亚声速区使用目标出口压力修正 | 不等价 |
| y- | 等温无滑移，壁面密度由连续性方程推进 | bctype=41 等温壁面 | 物理类型相同，密度/RHS/halo 闭合仍须逐项审计 |
| y+ | 分段 Dirichlet，直接给定守恒量 | bctype=52，sbli_shock NSCBC 目标 | 不等价 |
| z | 原参考为二维 | ASTR 拟薄层周期挤出 | 属于复现适配，不是参考原始设置 |

入口实现细节见论文 3.3.6：入口 halo 保存规定剖面；局部 u>=a 时将规定状态复制到入口，
u<a 时使用内部压力设置能量以允许上游传播。实际边界点与 halo 的操作顺序应继续读边界类确认，
不可仅凭文字自行发明压力外推阶数。

顶面守恒量已由归档 HDF5 和论文示例代码交叉核对：

| 量 | x<=40 | x>40 |
|---|---:|---:|
| rho | 1.00000596004 | 1.129734572 |
| rho*u | 1.00000268202 | 1.0921171 |
| rho*v | 0.00565001630205 | -0.058866065 |
| rho*E | 0.94644428042 | 1.0590824 |

激波前法向速度非零，不能沿用现有默认 V=0 再凭标称角重新生成状态。
建议归档复现使用这组守恒目标，并检查转换后的 EOS 与正性；角度用于几何解释，不再用来覆盖已锁定状态。
顶面不添加 ASTR 特有的 NSCBC 横向滤波。体积滤波是否使用需单独作为数值方案说明及敏感性测试。
保留原 NSCBC 路径作为后续边界敏感性对照，不全局替换 bctype=52。

## 5. 必须解决的资料冲突

1. Prandtl 数：论文表 4.2 写 0.71，但同一论文的示例代码及固定版本公开源码均为 0.72；
   `katzer_init.py::load_similarity` 也显式采用 0.72。
   HDF5 没有 Pr 元数据，不能据此宣称 2018 年归档实际必为 0.72。
   建议先寻找对应 2018 年生成版本或向作者确认。暂以源码值 0.72 作为候选，不能标记为已锁定。
2. 壁温：归档为 1.676194，后续源码为 1.67619431，论文表为四位有效数字。
   对归档数据复现优先使用归档值；记录舍入差异。
3. 后续源码默认 500x250、dt=0.04、250000 次推进，不是归档的 609x255、t=13000。
   不直接执行下载示例，也不从后续源码推断归档 dt。
4. ASTR 当前 Sutherland 常数在 `src/solver.F90::refcal` 和相似解生成器中是 110.3 K，
   与参考的 110.4 K 不同。需可配置的 CPU/GPU 共享物性参数或显式记录偏差，不能暗改全局默认。

以上是工况差异或证据缺口，并非本轮认定的 CPU BUG。求解器改动须单独确认。

归档 Cf 零交叉经相邻两点线性插值得到：
x_sep=139.3790949856823，x_reattach=288.9972926232371，长度约 149.6182。
这是参考数组的诊断结果，不是 ASTR 已取得的结果，也不是理论精确位置。
不能把论文描述的压缩波起点直接当作 Cf=0 的分离点。

后续源码 `plot.py::compute_skin_friction` 使用
Cf=2*mu_star/Re*(du_star/dy_star)_wall，采用自由来流动压归一化。
`SBLI_comparison` 使用 p_wall(x)/p_wall(x=0)。
正式后处理应复核归档 Cf 与独立壁面导数的对应，避免将不同离散求导误差误认为求解器场误差。

必须分别验收：同相位 CPU/GPU 数值误差；时间收敛；网格收敛；外部数据物理误差。
论文以 t=13000（32.5 个域穿越时间）为比较点，延长到 t=26000 后分离长度变化约 0.4%。
不能将这些无量纲时间写成步数，也不能仅以“不出现 NaN”判定收敛。

## 9. 入口连续性门槛：问题发现记录（修复前）

用户已要求开始 OpenSBLI 层流验证。执行首项入口检查时发现独立于 Pr 资料冲突的数学错误。
位置：`generate_compressible_blasius_profile.py::map_similarity_profile` 第 125 行，
以及 `write_similarity_initial_field` 第 246 行。两处都采用了相同的错误法向速度表达式。

定义 Y(eta)=integral_0^eta T(s) ds，已有代码的坐标关系为
y=sqrt(2*x/Re)*Y(eta)，流函数 f 满足 f'=u，rho=1/T。
由稳态连续性 d(rho*u)/dx+d(rho*v)/dy=0 和壁面 v=0 推出

```
v = (u*Y - T*f) / sqrt(2*Re*x)
```

原实现使用 `T*(u*eta-f)/sqrt(2*Re*x)`，将 Y 错当成 T*eta。
仅 T 为常量时二者相同，温度随法向变化时不成立。
这是 ASTR 测试输入生成器的问题，不是新发现的 CPU Fortran 边界程序错误。
CPU/GPU 都使用同一错误入口时，逐场一致仍可能通过，不能据此证明入口物理正确。

可复现检查（不启动 CFD，不改参考数据）：

```
python3 tests/gpu_validation/check_blasius_mass_continuity.py
```

该诊断显式返回退出码 1，当前 `passed=false` 是真实门槛失败，不是已修复结果。
用当前生成器的 Pr=0.72、S=110.3 K，M=2、Tinf=288 K、Tw=1.676194，
按可压缩位移厚度归一化为 1 后：

| 相似解点数 | 原公式连续性最大残差 | 独立连续性表达式残差 |
|---|---:|---:|
| 2001 | 2.83777918e-3 | 2.92702552e-8 |
| 4001 | 2.83780931e-3 | 7.31765961e-9 |

残差是在固定物理 y 下按自相似缩放计算流向质量通量导数，再用非均匀 y 差分计算法向导数。
独立表达式随加密约二阶收敛，原公式残差不随加密减小。
4001 点时原外缘 v=0.00277462053，独立表达式 v=0.00564923052。
归档顶面 rhov=0.00565001630205 仅作量级交叉检查，不用于拟合或强迫新表达式。
两者剩余差异还包括物性常数、拟合和参考生成版本，不能宣称此时已精确匹配 OpenSBLI。

建议修复范围（未执行）：同时修正上述两处表达式，统一使用累计积分温度坐标；
补充等温极限、可压缩连续性、入口与全场切片一致性的测试，再重生成受影响的相似解算例。
旧结果仍可作为旧输入下的 CPU/GPU 等价证据，但相似解物理验证需重新评估。
按项目约定，等待人工批准后修复；不继续用错误入口跑长时间 SBLI。
