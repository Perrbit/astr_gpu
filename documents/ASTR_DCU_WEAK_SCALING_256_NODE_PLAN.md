# ASTR DCU 256 节点弱扩展测试计划

**状态：本地前置验证完成，DCU 平台未运行。** 三条主线为显式 TGV、全紧致 TGV 和 AIR5 反应 TGV。最高 256 节点、1024 DCU，按历史同型 16 GiB 档、每节点四卡、一 MPI rank 一卡设计。256 个同型节点的可分配性、资源配额和网络尚未核实。本文不授权登录、查询或提交平台任务。

## 1. 冻结配置

每条曲线固定每卡网格区间、物理网格间距、时间步和每轮五个完整步。增大节点数时扩大周期盒、按整周期重复同一个初场，不在原盒内加密，也不改变参考长度、物性、机理或边界。三条曲线以各自一节点四卡为基线，不比较三种方法的绝对快慢。

| 项目 | 显式 TGV | 全紧致 TGV | AIR5 反应 TGV |
| --- | --- | --- | --- |
| 初场 | 周期 `tgv`，继承单组分 `Re=1600、Ma=0.1` | 同左 | 内置周期 `air5tgv`，五组分双温，参考长度 `0.01 m` |
| 一节点区间数 | `488³` | `442³` | `336³` |
| 每 rank 固定区间 | `244×244×488` | `221×221×442` | `168×168×336` |
| 对流 / 黏性 | FP64 `643e/643e` | FP64 `643c/643c` | FP64 `643e/643e` |
| 滤波 | 十阶显式，单分量工作区 | 全方向 `compact10`，单分量工作区 | 关闭 |
| 时间推进 | RK3，固定 `dt=1e-4`（无量纲） | 同左 | RK3 与两次真实化学半步，固定 `dt=2e-10 s` |
| 本地优化 | 黏性同轴合包，优先验证 z 优先 | 接口 PCR 单缓冲，批 RHS 上限 `65535` | `packed`，化学专用核固定 128 线程，关闭化学补偿和线程块学习 |
| 应用层主候选 | 设备缓冲 MPI | 普通 halo 和接口 PCR 均使用设备缓冲 MPI | `device + packed`；保留独立设备收发槽 |

三条路径均从同一待确认的源码快照构建 FP64 CUDA C++ / DTK GPUFusion 程序；保留各路径的可执行文件 SHA-256、编译选项和动态库指纹，不把历史强扩展的可执行文件当作这次已定基线。跨节点主目标均为**设备缓冲 MPI + 经证实的原生 IB RDMA**，设备内存直访另作取证。外层与紧致接口均采用已验证的依赖同步，不取消 MPI 读写缓冲前后的必要同步。普通 halo 的设备选项是 `ASTR_GPU_HALO_TRANSPORT=device`；紧致接口独立用 `ASTR_GPU_COMPACT_TRANSPORT=device-aware`，不能只设置其中一项。

普通 TGV 以边长 $2\pi$ 的基本周期盒为单位，AIR5 以 $2\pi\times0.01\,\mathrm{m}$ 为单位。每节点负责一个基本盒，但相邻盒之间是普通子域接口，不是独立边界；只在全域外边界周期回连。因此全紧致的线仍跨完整全局轴：每 rank 的局部线长和批容量不变，方向组与接口 PCR 影响整步耗时。256 节点的三轴接口主 PCR 分别为 4、3、3 轮，不含周期校正和端点恢复。

按历史同型算例的最大对流／声学 CFL 和网格间距折算，上表原步长分别预计约 `0.249 / 0.225 / 0.00583`，须用新输入实测。AIR5 的这个 CFL 不约束化学刚性，要另看实际接受／拒绝、RHS／Jacobian 工作量和状态合法性。不按节点数改变 dt，不启用自动步长；若预检否决当前步长，重新审阅并重定整条曲线的基线和所有档位。

## 3. 容量、网格初始化和整数范围

历史 16 GiB 档设备可见约 **15.98 GiB/卡**，80% 约 **12.79 GiB/卡**。以下为按历史记录校准的规划值，以四卡中的最大占用为准；不设应用内显存硬上限，不称下表为当前程序实测。

| 算例 | 最大卡占用估计 | 已包含通信区 | 每节点主机数组粗估 |
| --- | ---: | --- | ---: |
| 显式 | 12.81 GiB，80.1% | 普通收发槽约 0.19 GiB/卡 | 92.5 GiB |
| 全紧致 | 12.75 GiB，79.8% | 普通槽约 0.11；线求解及接口工作区约 3.31 GiB/卡 | 69.0 GiB |
| AIR5 | 12.67 GiB，79.3%；z 分解后约 12.81 GiB，80.2% | 普通与私有槽合计约 0.69；分配 z 私有槽后另增约 0.14 GiB/卡 | 41.6 GiB |

`hm=5`，带 halo 的三维场按 $\prod_d(n_d+11)$ 计；普通通信四个设备槽按最大分布轴面和容量计算，AIR5 私有黏性槽还要累加分布轴。紧致另计三轴单缓冲计划和固定批容量。主机值不包含完整 MPI/UCX 私有开销，`pinned` 对照另计页锁缓冲；显式和紧致不能直接沿用 64 GiB/节点。资源计划先沿用 8 CPU 配额/rank、求解单线程，以一节点实测和分区 CPU/内存配比定最终配额。[历史容量模型和实测](ASTR_MULTI_NODE_COMMUNICATION_OPTIMIZATION_PLAN.md#91-m0-算例参数审阅表)

正式运行的本地前置工作：

1. **先提升全局计数再相乘。** 现有几何统计和场统计中有先算默认整数 `ia*ja*ka`、再转换实数的路径。显式和紧致在 32 节点、AIR5 在 64 节点首次超出有符号 32 位全局区间计数；最大档约有 297.51、221.06、97.11 亿区间。核查几何归一化、统计、日志及全局线性偏移，必要时改为 64 位；同时验证本地索引和 MPI 计数接口的边界，不用全局修改默认整数宽度的编译选项。[几何归约示例](../src/geom.F90#L637) · [报告计数示例](../src/readwrite.F90#L3227)
2. **本地生成坐标，不预写全局网格文件。** 设置 `lreadgrid=f`，复用 `gridcube` 的 rank 内生成，基准专用的三向盒长度随节点格放大；保留合法且关闭各场产品的 `input.output`。256 节点的显式网格若写三份 FP64 坐标，约 665 GiB。现有无场 I/O 基准拒绝 `air5tgv`，需联合验证三维周期 AIR5 准入、本地产网格及启动至退出无大场文件。基准开关要求启用 GPU RK 计时，但 AIR5 的正式数据仍应取完整反应步计时。不改初场公式、参考量或生产默认。[网格入口](../src/gridgeneration.F90#L25) · [本地坐标生成](../src/gridgeneration.F90#L310) · [无场 I/O 准入](../src/benchmark_runtime.F90#L140)
3. **统一跨规模统计口径。** 普通 TGV 的现有 GPU 拟涡能以 $x_{\max}/(2\pi)$ 为长度，放大周期盒会仅因归一化而放大报告值。保留原日志；跨档比较按基本盒长度换算，即按本方案将原拟涡能除以 x 向基本盒重复数的平方。小网格预检用重复初场核对换算值及归约，不用原始拟涡能跨档差判定数值失败。[GPU 统计定义](../src_gpu/fluid_runtime.F90#L1823)
4. **保留一次 1024 rank 小网格启动核对。** 在获批的目标分配内，正式尺寸前复用同一放置做一项代表性小网格检查。仅三个方向组的创建在目标分解下就有 320 次全局集合调用；记录启动、通信域创建与正常退出，核对组大小和坐标顺序。失败或超时则不进入正式计时；只在证实启动瓶颈后才提出改动，不先重写域分解。[通信域构建](../src/parallel.F90#L836)

## 4. 通信路径的选择与资格验证

- 先冻结实际一 rank 一卡与 NUMA／HCA 放置，记录 MPI 与 UCX 版本、实际端口和代表性消息采用的协议。区分「MPI 接收设备地址」「应用没有主机暂存」「跨节点采用原生 IB RDMA」和「HCA 直接访问设备内存」。对显式 halo、紧致端点消息、AIR5 私有通量各查看代表载荷；不以单个 UCX 传输名宣称所有尺寸均绕过主机。
- 四节点按相同网格、分解、分配、绑核、固定 dt 与 MPI/UCX/PML/HCA 栈做代表配对。**显式合包只支持 `device`：先在 `separate` 下比较 `pinned/device`，再在 `device` 内分别核对合包和 x/z 调度。** 本次四节点分解为 `4×2×2`，不能用历史 `2×2×4` 的 z 优先结果替代。紧致配对同时切换普通 halo 和接口两项缓冲方式，保持批上限、单缓冲及同步不变；AIR5 固定 `packed`。无法固定底层栈时只报告端到端对照，不把差异归因于缓冲方式。
- 配对先在同拓扑小网格上验证同相位状态：显式、紧致五个守恒分量沿用逐分量最大缩放差 $\max|q-q_{\rm ref}|/\max(1,\max|q_{\rm ref}|)\le 2\times10^{-10}$；AIR5 纯通信切换沿用第二次化学半步后的 `q11` 逐位对照，并核对组分和双温合法性。正式尺寸按完整步选型，差异未超出重复波动就不宣称加速。历史 AIR5 设备缓冲已到 16 节点，不能据此认证 256 节点或全部消息直访设备内存。[显式合包准入](../src_gpu/fluid_runtime.F90#L388) · [AIR5 同状态证据](ASTR_MULTI_NODE_COMMUNICATION_OPTIMIZATION_PLAN.md#12-air5-跨节点-device-mpi-修订)
- 选定后在整条曲线冻结传输和模式。一节点仍采用相同应用缓冲后端；其节点内通信不称为跨节点 RDMA。规模失败保存原始日志与已完成点，停止依赖该失败档位的扩展；不自动更换后端、混入同一曲线或自动重试。

## 5. 计时、误差与交付

**每轮独立启动 5 个完整步，前 2 步预热，只计第 3–5 步。一节点 3 轮，其他档 2 轮。** 同档可在同一分配内按同配置跑两次；重复反映该分配和启动条件下的波动，不等于独立抽样不同节点。完整矩阵 27 个算例/规模组合、每条曲线 95 个完整步。AIR5 每轮至 $t=10^{-9}\,\mathrm{s}$，核对三阶段 RK 输运及每轮 10 个真实化学半步。

对每步取全 rank 最大耗时并保留最慢 rank 编号；按第 3–5 步求轮内中位，再取轮中位数的中位 $T_N$（两轮时取均值）。缺 rank、重复记录或未完成五步的轮次不计入正式结果。显式和紧致用 `ASTR_GPU_RANK_RK_TIMING` 的完整 RK 推进；AIR5 用 `ASTR_COMPLETE_STEP_TIMING`，包含两次化学半步以及计时区间内启用的检查、监控或统计。归档实际启用项，不称 AIR5 的值为纯化学或纯 RK 核时间。初始化、预热和计时区间以外的工作单列。关闭全局网格写出、常规场、切片、检查点、原位、profiler 和逐阶段诊断；保留轻量 CFL、时钟和数值诊断。显存定标、配对抓包及分解诊断与正式计时分开。

报告完整步耗时、弱扩展效率 $E_{\mathrm{weak}}(N)=T_1/T_N$，以及全局唯一区间数除以 $T_N$ 的更新率。记录实际 GPU/节点数；代表诊断批附有效载荷和暂存证据，不要求所有正式轮开详细计数。紧致单列方向组长度、接口 PCR 轮数、线长和 RHS 批数；AIR5 单列化学接受／拒绝、RHS／Jacobian 工作量和关键状态极值。常规化学日志的 `max_acc/rej/rhs/jac` 是全域最大值，不是每 rank 工作量总数；需要解释慢 rank 时再从单独诊断核对两次化学半步的每 rank 计数。MPI 主机等待不是纯网络时延，不与设备活动相加当作时间分解。

历史 1/2/4/8/16 节点强扩展共 45 轮截窗复算：按本版**一节点三轮，其余任取两轮**，相对历史「三轮 2+20」的最大步时偏差为显式 **2.75%**、紧致 **0.92%**、AIR5 **6.16%**；由对应节点步时比得出的最大偏差为 **2.82% / 0.97% / 0.93%**。AIR5 早期化学工作随物理时间变化，不能用长窗一节点步时配短窗大规模步时。这些不是 256 节点置信界，短窗不用于声称 1%–2% 的优化收益。若两轮差异足以改变后端选择或扩展曲线的解读，先核查慢 rank、路径与化学工作，再决定是否另补第三轮。

## 7. 本地交付与验证

根 CMake 构建了含 AIR5 的 C++ CUDA 后端及 `astr_backend_weak_scaling_count`。后者用合成尺寸验证 256 节点三条路径的全局唯一区间数为 `29,750,853,632`、`22,105,827,328`、`9,710,862,336`，另验含周期端点的计数，没有分配相应大场。几何归约、CPU 对照统计及步进报告使用先转 64 位再乘的计数；GPU 主统计原有逐轴转换不变。基准通过 `benchmark_tgv_tiles` 显式放大周期盒，坐标由各 rank 本地生成。

[输入与日志工具](../tests/gpu_backend/prepare_dcu_weak_scaling.py)的 `prepare` 生成 27 份输入和同一份 `campaign.json`；`check-placement` 以观测到的 `rank`、`coords`（零基）和 `host` 核对节点 `2×2×1` 分块，不假设世界 rank 在同一节点上连续；`reduce` 和 `summarize` 分别归约单轮日志和整组重复，缺失轮次保留为空。合成输入核对了错放 rank、缺记录拒绝，以及第 3–5 步取最慢 rank 后再取中位的口径。

在本地两张 RTX 4000 Ada 上，[短测脚本](../tests/gpu_backend/run_dcu_weak_scaling_local_gate.py)以每 rank `16³` 对照单周期与两 rank 扩域。各配对网格间距一致，初场重复、周期接缝及五个固定步通过检查；AIR5 每次运行记录了十个化学半步。下表是配对场的最大缩放差。正式模板不启用场输出，短测只开启比较所需的逐 rank 小快照，未写全局坐标或大场文件。
