日期：2026-10-05。工作树：`feature/gpu_dev`，基于
`4f474409f843b393be4d4395dd38c79d3c76942d` 的未提交 IS6/IS7 增量。

## 1. 范围与支持矩阵

| 组合 | 实际验收范围 | 数据与续接 | 明确边界 |
| --- | --- | --- | --- |
| 周期笛卡尔 TGV | 32³，FP64，643e；NP=1/2 x/y/z，另有 NP=4 的 2×2×1 | 瞬时速度切片、Q、流线，Reynolds/Favre 速度矩与平均流线；同拓扑精确续接 | 其它 NP=4 拓扑不准入；流线不周期回绕 |
| 按产品供给 | `all/q_surface/streamlines/q_streamlines/velocity_slice` | 只供给所选字段；索引平面含空 rank；JPEG/EPS/VTK | 非笛卡尔任意截面和任意产品组合不自动准入 |
| 笛卡尔 bc41 槽道 | 16³，CPU/GPU，NP=1/2 x/y/z | 两壁压力、有符号剪切、入气体导热；时间矩、可选平均壁面图；同拓扑续接 | 无量纲，不自动转换 Cf/St；非 bc41 壁面另验 |
| AIR5 底壁 | 16³ 已登记热气体夹具，NP=1/2 x/y/z | SI 壁面物性、组分、分项/总热流；壁面及可选体统计、平均图；同拓扑续接 | 不开放一般 AIR5 三维渲染；零来流夹具的分离物理诊断不适用 |
| 静态周期 CURVE | 32³，映射幅值 0.15，NP=1/2 x/y/z | 完整九项度量的物理梯度/Q；Gauss 体积权重；跨分区流线、统计、同拓扑续接 | 不开放 CURVE NP=4、移动网格或一般几何 |
| 静态 CURVE bc41 壁面 | 32³ y-wavy TGV 诊断，NP=1/2 x/y/z | 几何法向/切向剪切与导热、Gauss 面积、壁面矩及图像 | 制造诊断，不是充分发展槽道或 SBLI；不开放任意曲壁/AIR5 曲壁 |
| CPU 原位统计 | 对应 TGV、bc41、AIR5 与已登记静态 CURVE | 正式累计和同拓扑精确续接 | 原生 EGL 渲染要求 GPU 求解器绑定，不支持 CPU 渲染 |

上述组合保留完整步相位。启用渲染不意味着全设备处理：
GPU Q 候选仍下载选定场、在主机完成节点归属重建并上传私有速度；
VTK 提取和图像编码仍用主机资源。壁面通道下载紧凑三层数据而非全域体场。
全设备过滤、异步、在线交互、渲染/新原位统计重分区属于 IS8，未开放。
分离零点算法已由合成剪切序列验收，不据此宣称生产分离泡物理通过。

## 2. 依赖与启动

本地构建为根 CMake 的 CPU+Catalyst、CUDA+Catalyst 和
CUDA+AIR5+Catalyst 三种构建。使用 NVHPC 26.1、HPC-X、HDF5 1.14.6，
Catalyst 加 ParaView 6.1.1 的 EGL 实现。ParaView 流线坐标 FP64 补丁及
重建方法保存在 `scripts/insitu/patches/`。不应用该依赖补丁的发行包
不能直接沿用解析流线 ≤2e-10 的结论。EGL 设备 UUID 必须匹配求解器 CUDA
设备，不能以设置了设备序号代替实际上下文核验。

独立启动入口不导入测试模块，也不内置本机依赖路径：

```bash
ROOT=/absolute/path/to/astr_gpu
EXE=/absolute/path/to/catalyst-enabled-cuda/astr
MPIEXEC=/absolute/path/to/compatible/mpiexec
CATALYST_LIBRARY=/absolute/path/to/paraview/lib/catalyst
CASE=/absolute/path/to/new-empty-parent/is7-tgv-np2
python3 "$ROOT/scripts/insitu/start_tgv_acceptance.py" \
  --output "$CASE" --executable "$EXE" --mpiexec "$MPIEXEC" \
  --library "$CATALYST_LIBRARY" --np 2
```

已有输出目录拒绝覆盖。`--prepare-only` 只生成输入；`--off` 只关闭新原位
开关，保留完全相同的 checkpoint 和物理设置。输入模板在
`scripts/insitu/presets/tgv32/`。这是验收模板，不是长期生产配置。
模板保留原位置式读取器要求的标题/空行，不可任意精简；启动器预建两个
独立的空输出根目录。实际独立 NP=2 启动回执为
`tests/gpu_validation/out/insitu_is7_standalone_final_20261005/`：四步运行成功，
十个 JPEG/EPS/VTK 产品帧和原生资源记录通过，与匹配开启组的14项
权威 HDF5 数据集逐值一致；目录97,211,809 B。最终模板位置/目录检查
另有9项通过，回执`insitu_is7_template_complete_20261005.xml`。
启动前须配置编译依赖的运行库搜索路径并检查设备/后端能力。
外部 20 ms 资源采样由验收驱动执行，独立入口保留原生阶段观察，
两者都不保证捕获所有第三方瞬时分配。

## 3. 匹配计时定义

只比较同一后端的原位开/关。网格 32³、dt=1e-3、四个完整步，
NP=1 和 NP=2 的 2×1×1 分解各一对。六阶中心显式差分、十阶显式滤波、
RK3、FP64、scalar 滤波工作区、pinned halo 和显式同步保持相同。
旧统计/旧场输出关闭，两组都每步保存新 checkpoint，保留最近两份。
开启组正式统计窗口 [0.003,0.004]，不删减端点样本；第 2/4 完整步
渲染既定预设，最终有覆盖时长时还输出 Reynolds/Favre 平均流线。
四种瞬时产品两帧加两种平均流线末帧，共十个产品帧，全部保存
JPEG、EPS 和分布式 VTK 几何，不通过缺图或降低频率缩短耗时。

各 rank 用本地单调时钟记录持续时间。某阶段先在每个 rank 内累计，
再取 rank 最大值，不相加进程时间，也不把逐次最大值相加。
完整窗口单独测量，不用阶段最大值之和重构总时间。
`ASTR_INSITU_TIMING=1` 开启细分日志，不新增逐阶段 MPI 屏障。

| 计时 | 边界及包含关系 |
| --- | --- |
| 求解器初始化 | MPI 初始化和计时设置之后，到进入 steploop；不含 pre-MPI 设备绑定 |
| 完整推进窗口 | 四步 RK、旧流程诊断、正式采样、渲染及新 checkpoint；不含初始化和最终释放 |
| RK 推进 `advance_inclusive` | 现有完整 time_integration_rk 调用，包含其原有诊断；不是孤立 kernel 时间 |
| 统计 `statistics_inclusive` | 正式累计及必要归约/主机管理，含初始样本和分配；不含后续统计 checkpoint 写出 |
| 同步/场下载 | 显式设备同步；场下载计时含 Fortran section 打包，不能改称纯 PCIe DMA |
| GPU 导数准备 | 私有速度建立、主机重建场上传、halo 及同步的包含式计时 |
| GPU 导数计算/打包/同步 | 私有诊断 kernel 加原有显式同步；随后另测其 cudaMemcpy D2H |
| Catalyst 初始化 | 首帧懒初始化，在完整窗口/首次 render 内，不重复加到总时间 |
| Python 提取 | 实际几何 UpdatePipeline 和标签/表面物化，先完成再交 writer |
| 渲染及截图 | Render 与 CaptureImage 分开；截图可能再次渲染，不能称纯像素传输 |
| 图像编码/发布 | 根 rank JPEG/EPS 内存编码，与磁盘双文件发布分开；等待仍在外层 execute 中 |
| VTK 写出 | writer 调用及错误共识，仍可能含第三方懒执行，不称纯文件系统时间 |
| 完成步输出 | 新 checkpoint，包括开启组新增统计状态写出；不是纯后处理图像 I/O |
| 总时间 | MPI 后求解器总持续时间；另记录启动器到子进程退出，后者含外部监测开销 |

`insitu_sample_inclusive/bridge/Catalyst execute/python_execute` 相互嵌套。
各表项不应相加；单独阶段最大值也不一定来自同一 rank。
本次无重复轮次置信区间，不据此给生产开销或 NP=1→2 性能结论。

## 5. 门槛与证据

主回执：`tests/gpu_validation/out/insitu_is7_final_20261005/report.json`。
记录实际可执行文件及管线 SHA256；源码/输入/环境变更后不能无条件沿用计时。

- NP=1/2 开关对照的权威场逐值一致。`control.bin` 仅允许已知
  ASTROC04 contract(12) 的新统计提供器标志由 0 变 1，其余逐字节一致。
- GPU NP=2 的计时开关不改变场、统计状态、控制、最终统计或 JPEG 像素。
  step3+1 配对续接与连续四步的状态、统计、控制、几何和对应图像一致。
- CPU NP=2 的计时开关及 step3+1 续接逐值一致；CPU/GPU 的唯一物理节点
  统计状态最大差约 1.55e-15，正式导出统计约 1.33e-15，均满足 ≤2e-10。
  GPU 统计检查点省略周期重复节点，不能把其零填充与 CPU 重复副本逐项比较。
- NP=2 实际全产品 GPU 路径有两份 Compute Sanitizer 报告，均为零错误。
  为隔离内存检查，memcheck 的 MPI 可选 CUDA 探测关闭；不据此声称
  CUDA-aware MPI 性能或渲染第三方全部内存绝对安全。
- 原生 CSV 与独立 20 ms 监测都通过既定预算；真实 JPEG/EPS 非空、
  VTK/完整步身份、解析跨分区流线及 EGL UUID 分别检查。

驱动开发中三类问题已定位，失败目录保留：基线参数传错 JSON 类型；
相对恢复路径再次按算例目录解析；把无物理归属的周期统计填充当成场量比较。
另修正控制标志的预期变化及窗口日志的完整步编号。没有修改物理定义、
数值方法、CPU 边界或放宽数值门槛。有效匹配计时只使用最终可执行文件，
修正驱动后复核指纹、输入和产物，未重复这些已完成的匹配计时。
独立模板启动还定位并修正数据行错位和未预建空输出根目录，未修改
原CPU读取器或新输出的目录保护语义。失败启动目录保留，最终实际启动
成功后才放行独立入口，不以仅生成输入文件作为启动通过。

受影响回归、明确拒绝和最终关闭情况在计划 IS7 收尾及验证矩阵登记。
`insitu_is7_regression_20261005.xml`记录25 passed、0 skip、126.45 s，
含实际节点主机、设备和共享设备观察超额拒绝、分配/余量拒绝、
CURVE/壁面/NP=4平面和AIR5受影响实际产品及续接。没有未解释数值失败。
IS0–IS6 的完整原矩阵保留原时间/指纹，本次不把旧回执伪装成全矩阵重跑。
