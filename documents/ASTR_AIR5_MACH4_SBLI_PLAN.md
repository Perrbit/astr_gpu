# Air5 Mach 4 低压 SBLI 推进方案

日期：2026-09-24。工况替换已经用户确认。保留旧 Mach 6 映射工况与失败证据。

## 工况与用途

本算例是固定五组分双温模型的工程耦合验证，不是指定论文的严格复现。
无激波平板由 ASTR 主程序预发展。Python 只准备数据、检查状态和管理运行，
不另建完整流动推进器。原压力域失败见
[诊断记录](ASTR_AIR5_SBLI_PRESSURE_DOMAIN_DIAGNOSIS.md)。

| 参数 | 设定 |
|---|---|
| 入口冻结声速马赫数 | 4 |
| 入口 T / Tv | 1500 / 1500 K |
| 入口压力 | 20000 Pa |
| 质量分数 N2/O2/N/O/NO | 0.767/0.233/0/0/0 |
| 入口速度 / 密度 | 3112.356772 m/s / 0.046248672 kg/m3 |
| 壁面 | 无滑移、非催化，T=Tv=3000 K |
| 入射激波角 | 相对入口边缘流向 25 度，不是压缩转角 |
| 冻结跃迁后的压力 / T | 63346.312859 Pa / 2177.259771 K |
| 冻结跃迁转角 | 12.937449 度 |
| 展向 | 周期、层流三维挤出 |
| 数值路径 | FP64、显式同步、现有 LLF/MP7、耦合源项、黏性、关闭滤波 |
| 本地并行 | NP=2，2x1x1，一 rank 一 GPU |

冻结规则反射压力估算约 0.1603 MPa，只是选型余量检查，不是黏性反应流峰值
保证。保留代码原有 1 MPa 压力上限及 300--8000 K 温度范围，此外新工况诊断
要求平动温度不低于 1000 K，以避免已有二元扩散拟合的低温外推。
换工况不能解决既有平衡常数拟合与热力学闭合之间的一致性问题；化学平衡
物理验证仍独立待做。不得把新短步通过写成这些模型问题已经解决。

## 起步网格与入口

`prepare_air5_mach4_case.py` 独立准备 `air5hbl`，不会打开激波顶面。
初始速度是有限厚度四次多项式种子：`f(s)=2s-2s^3+s^4`，`0<=s<=1`，
外部 `f=1`。`u=Uinf*f`，`v=w=0`，`T=Tv=Tw+(Tinf-Tw)*f`，
`rho=pinf/(Rmix*T)`，组分保持入口组成。
这不是可压缩双温相似解，必须先经 ASTR 预发展。

启动剖面以 `Re_delta_star=1000` 定标，位移厚度定义为
`integral[1-rho*u/(rho_inf*Uinf)]dy`。当前模型边缘黏度为
`5.40477883e-5 Pa s`，所得参考厚度 `0.37548214 mm`，种子总厚度
`0.97641532 mm`。预发展域 `80x12x2` 倍参考厚度，即
`30.03857 x 4.50579 x 0.750964 mm`。流经时间 `Lx/Uinf=9.65139 us`。
这些是起步参数，不是网格或入口物理收敛结论。

首轮网格上界 `63,63,7`，步长 `2e-9 s`。CFL 以实际输出为准，达到 1
或出现实际负组分、NaN、越界即停止。先进行短步 CPU/GPU 同相位比较，
再进行不超过一个流经时间的预发展试跑。确认趋势后才安排多流经时间收敛。
必须覆盖位移厚度、壁压和壁热通量的时间变化，不能仅凭任务正常退出判断稳态。

`air5_hbl_domain.dat` 是可选尺寸接口，首行为 `air5_hbl_domain_v1`，
第二行为 SI 单位的 Lx/Ly/Lz。无此文件时保留旧 air5hbl/air5sbli 的尺寸。
当前只用于内置 Cartesian 网格，不宣称验证外部曲线网格。

## 推进顺序与停止条件

1. 新配置数据检查、旧配置回归、根 CMake 编译。
2. 新平板 CPU/GPU 短步场、原始传感器、掩码与模型有效域检查。
3. 双 GPU 无激波预发展，保存完整 RK checkpoint 和少量统计，检查 CFL。
4. 多流经时间、步长和网格敏感性检查。提取 ASTR 自身演化后的剖面与初场，
   保留全组分、Tv 和法向速度。裁剪/移站后必须重新匹配入口、顶面和流向坐标。
5. 以实际边缘状态重新生成冻结入射跃迁，再做小规模 CPU/GPU 激波接入。
6. 通过后推进有界长时 SBLI；原始痕量/展向问题保留独立诊断记录。

计划顶面转折为 x=20 倍参考厚度。零入口偏转时几何落点约 x=45.734 倍
参考厚度；理想规则反射波重新到达顶面的 x 约为 85.8 倍参考厚度，超过
当前域长 80。实际预发展边缘法向速度、波系和边界层增厚会改变此估算，
必须在激波接入前重算，不允许预先认定完整状态顶面适用于最终波系。

禁止直接用解析种子或缩放旧 HTR 初场开始长时 SBLI 并称为物理验证。
新出现的 CPU/GPU 不一致或模型域错误仍是停止条件，不能援引旧展向误差豁免。

## 本轮结果

根 CMake CUDA/air5 编译通过，36 项数据准备/状态监控测试通过。
尺寸接口的错误头、负尺寸和 NaN 均由双 rank CPU 启动明确拒绝。
无尺寸文件的旧 SBLI 双卡回归通过：36 组场，最大缩放差 `8.51e-16`，
原始传感器及掩码一致。没有修改原壁面闭合、输运公式或模型有效域。

| 验证 | 本轮结果 |
|---|---|
| 新平板短步 | NP=2，63,63,7，20 次更新，dt=2e-9 s |
| CPU/GPU 同相位 | 18 组场，绝对差最大 2.33e-10，缩放差最大 3.35e-14 |
| 接受阈值 | 逐元素 1e-9 + 1e-10 abs(q)，不是把原始相对差用于近零分量 |

| 完整 RK checkpoint | step 1000，t=2.000 us；末次更新结束 t=2.002 us |
| 最大 CFL | 0.067698 |
| 末步 18 组阶段快照 | T 1499.9597--3000 K；p 19.68986--21.46382 kPa |

上表墙钟时间不是性能基准。运行期间 nvitop 确认两个 ASTR rank 分别占用
GPU 0/1，单次观测利用率约 45%/59%。服务正常结束，无继续后台长跑。

末 checkpoint 的 N、O、NO 最大质量分数分别约为 `8.10e-11`、`8.07e-7`、
`6.61e-10`，说明当前时段化学作用较弱，不能据此完成强反应 SBLI 验证。
约 x/Lx=0.25/0.5/0.75 的位移厚度为初始值的
1.02108/1.02329/1.02329 倍，域内仍大范围受初始种子控制。
展向扰动增长已记录，不把其归因确定为舍入误差，也未接受其长期稳定性。

当前结论为有界预发展状态检查通过，不是充分发展、网格收敛或 SBLI 物理通过。
下一步仍是多流经时间平板、壁面响应和分辨率检查，再提取匹配入口及初场。
本轮没有施加入射激波。

## 续算与时间演化检查

step 1000 同一完整 checkpoint 的 CPU/GPU 单步重放通过，18 组场最大
缩放差 `1.86e-12`。GPU 重启与原连续运行相同步骤/阶段比较也通过，18 组场
最大缩放差 `2.95e-12`，两组比较的传感器掩码均一致。改变 dt 为 `1e-9 s`
的两次更新另外检查了续算时钟：checkpoint step 1001 对应 `2.001 us`，
不能误用全局 step 乘新 dt 得到 `1.001 us`。

`run_air5_sbli_long.py --baseline` 从不可变的案例归档新建续算目录，要求
可执行文件和机理与基线一致，并继承网格。原 checkpoint 和初场不覆盖。
流动仍由 ASTR 完整推进，Python 只管理任务、保存完整 RK checkpoint 和诊断。

```bash
python3 tests/gpu_validation/run_air5_sbli_long.py \
  --case mach4-precursor \
  --baseline tests/gpu_validation/out/air5_mach4_precursor_pilot_20260924/gpu \
  --executable tests/gpu_validation/out/air5_mach4_precursor_pilot_20260924/astr \
  --updates 4001 --dt 2e-9 --checkpoint 500 --timeout 1800 \
  --output tests/gpu_validation/out/mach4_ft1_new
python3 tests/gpu_validation/check_air5_precursor_evolution.py \
  --output tests/gpu_validation/out/mach4_ft1_new
```

目标完整 checkpoint 为 step 5000、`10.000 us`，末更新为 `10.002 us`，
约 1.036 个流经时间。先检查一个流经时间的变化，再决定多流经时间计算。

诊断在固定 x/Lx 约 0.25/0.5/0.75 的节点上进行。位移厚度采用
`integral(1-mean_z(rho*u)/mean_z(rho*u)_edge)dy`，周期端点只计一次。
保存温度、Tv、速度、密度、压力和全部组分剖面。
壁面摩擦系数为 `2*mu_w*du_dy_w/(rho_inf*Uinf^2)`，导热为
`-k_tr*dT_dy-k_v*dTv_dy`，正值表示从下壁进入流体，单位 `W/m^2`。
非催化壁面法向组分扩散焓通量取已施加的零值。
后处理沿用已有七点单边导数权重，逐展向点计算后平均，属于独立壁面观测量，
不冒充求解器离散 RHS 中的边界通量，也没有修改壁面格式。

后处理只输出时间历史与最近窗口变化，不自动给出稳态/物理通过。
热流穿过零值时相对变化可超过 100%，须同时看带符号的绝对值。
早期热流由正转负与摩擦仍变化，表明不能只凭壁压波动较小提取稳定入口。

### 一个流经时间与法向加密结果

上述 4001 次续算正常结束，step 5000 完整 checkpoint 为 `10.000 us`，
末更新 `10.002 us`，约 1.036 个流经时间。最大 CFL `0.0710347`。
末步 18 组阶段快照的 T 为 `1488.882--3140.055 K`，p 为
`19.5948--23.2655 kPa`，无负部分密度，组分和最大相对残差 `3.07e-13`。
最后 checkpoint 的 `max(abs(w))/Uinf=4.26e-8`，过程中曾升高后回落。
这些仅是有界运行与状态检查，不是稳态或长期挤出稳定性通过。

壁面剖面已有锯齿状变化，单边导数结果对模板非常敏感。
例如 x 节点 16、step 5000，七点与三点诊断分别得到：

| 量 | 七点 | 三点 |
|---|---:|---:|
| Cf | 0.0220815 | 0.00302715 |
| 向流体热流 W/m2 | +2025851 | -122498 |

所以此前七点诊断的变号不能直接解释为真实壁面分离或传热方向改变。
三点诊断只是另一个敏感性对照，不能挑选较平滑的结果来宣布物理通过。
最后 `9--10 us`，节点 16 的三点 Cf 和热流变化仍约 44% 和 45%；
节点 32 的热流变化约 25%，尚不能提取稳态入口。

随后保持物理域、初始解析种子、dt、源项和边界不变，仅将网格上界从
`63,63,7` 加密为 `63,127,7`，双卡从 t=0 推进 1001 次更新。
加密计算正常结束，最大 CFL `0.0989005`，末步 18 组阶段状态检查通过。
比较严格取两个网格的 step 1000 完整 checkpoint，即相同 `t=2.000 us`，
不是用粗网格的 10 us 与细网格的 2 us 混比。

| 对比量 | 64 与 128 个法向点的差别 |
|---|---|
| 位移厚度，3 个站位 | 相对细网格约 0.154%--0.289% |
| 壁压，3 个站位 | 相对细网格约 1.058%--1.075% |
| 三点 Cf | 相对细网格约 18.56% |
| 三点壁面热流 | 相对细网格约 9.47%--9.96% |
| 七点 Cf / 热流 | 相对细网格约 107% / 181%，更敏感 |
| max(abs(w))/Uinf | 粗网格 1.38e-9；细网格 1.25e-14 |

以上百分比是两个网格的差，不是相对真解的误差。
细网格在 2 us 的展向扰动降低，不能推断其 10 us 或更长时间也已稳定。
新工况解决了本轮物性域覆盖问题，但近壁分辨率、导数闭合和启动调整仍需分离。
未据此认定 CPU 边界存在明确 bug，也未修改求解器格式。

下一步先做相同物理时间的时间步敏感性和进一步法向分辨率检查，并审查
入口启动与近壁输运离散的相容性。壁面量尚敏感时，不盲目追加多流经时间，
不施加入射激波，不形成 SBLI 物理结论。涉及 CPU 格式修复时仍须人工决策。

本轮证据位于 `tests/gpu_validation/out/`：

- `air5_mach4_late_restart_gate_20260924/`：晚期后端与重启连续性对照。
- `air5_mach4_restart_clock_20260924/`：改变 dt 的续算时钟检查。
- `air5_mach4_precursor_ft1_20260924/`：一个流经时间，时间历史与阶段场检查。
- `air5_mach4_precursor_y128_20260924/`：法向加密及 `grid_comparison.json`。

`precursor_evolution.json` 使用实际保存的质量通量先求展向平均，再积分位移厚度。
第一轮续算运行中的在线剖面诊断使用平均 rho 与平均 u 的乘积，该运行脚本已
按启动 hash 归档为 `driver_at_launch.py`；离线诊断已统一为严格质量通量定义。
两者不改变 ASTR 的状态推进，正式时间历史取离线重新计算的结果。

### 首点 y+ 与入口敏感性

已完成 [分辨率与入口审查](ASTR_AIR5_MACH4_RESOLUTION_INLET_AUDIT.md)。
128 点在 t=2 us 的首点 y+ 仍为 1.375--1.504（三点）或 1.566--2.489（七点）。
同一 checkpoint 出发的入口厚度 0.9/1.0/1.1 倍双卡短时对照全部正常结束。
在 t=3 us，近入口节点 2 的三点热流相对基准变化 +21.39%/-22.51%，
域中部则几乎无变化，仍不能关闭壁面导数模板敏感性或长时间入口相容性。
保持原格式与模型；后续同物理时间的 128/256/512 点加密和 dt/2 检查已完成。
首点 y+<=1 为设计参考，不替代层流壁面热流、剪切及两温/组分剖面收敛。
三组正式计算有界通过，但 y512 的近壁模板差异仍明显，入口首列的七点热流
还存在约 20%--22% 的时间步敏感性。当前不关闭平板/SBLI 物理门槛，
下一步先定位入口与近壁输运耦合，不自动修复 CPU 格式。完整数值见上述审查报告。
