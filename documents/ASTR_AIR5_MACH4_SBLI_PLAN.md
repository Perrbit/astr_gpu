## 2026-09-26 全流场补偿实施契约

按本轮批准实施，以下内容取代下一节中的“尚未接入”当前状态，但不覆盖
既有失败证据。生命周期短门槛及 L1 三档同窗数值门槛已通过。

- 当前余量及 SSP-RK 起点高位/余量各占 11 个 FP64 分量，仅在候选启用时
  分配。RK 采用原 SSP-RK3 的仿射增量形式，保存差值的 TwoDiff 余量，
  不再将大状态的 Jacobian 乘除舍入作为下一步唯一状态。
- 化学六分量沿用已验证的自适应 ROS-2 事务提交语义。源项和物性查询仍
  使用 FP64 高位状态，不宣称提供双倍精度的热力学计算。
- 边界重新给定的状态拥有新的零余量；内部重复节点保留两侧信息，并补偿
  `0.5*(q_left+q_right)` 的舍入。实际高位交换仍使用原来的 qswap 路径。
  余量不参与空间 RHS 的 ghost 查询，不为不被推进的 ghost 分配持久余量。
  每个完整步末尾执行高位和余量的重复节点合并，不能只在输出前合并，
  否则检查点会丢掉另一 rank 的独立余量，且结果依赖输出频率。
- 检查点必须同时保存高位和余量，仅在完整时间步边界续算。不允许把
  primitive-to-conservative 重构后的不同高位配上旧余量。
- 默认关闭；旧 checkpoint 需要明确选择零余量初始化。无版本、缺字段、
  非有限值或非低位尺度的余量不能被静默当成正常补偿续算。
- 本轮先验证无滤波、无海绵层的 HBL/SBLI 路径。冻结质量闭合 128 epsilon、
  非负性和物性适用域门槛，不使用归一化或 N2 残差吸收。
  自动 crash-fix 改写状态而不维护余量，因此补偿候选明确拒绝该选项。

准入顺序：基础算术/MPI探针 → 实际 CPU/GPU 短步 → 同相位逐场比较 →
连续与分段重启的高位/余量逐位一致 → 拒绝非法重启 → memcheck → L1。
L1 任一失败时不运行 L2/L3，也不宣称完整补偿或物理验证通过。

生命周期结果与路径见当前状态文档首节。CPU/GPU NP1/NP2 短步符合既定
逐场门槛，各自连续/重启的 22 个字段逐位一致。最终候选的 GPU 重启路径
双卡 memcheck 零错误。补偿默认关闭，L1 明确使用 `on`，旧 checkpoint
明确使用 `initialize`，不恢复历史上不存在的低位信息。

L1 的 2/1/0.5 ns 分别完成 100/200/400 次完整更新至 2.38 us。
各组首末步 40 份 rank/stage 快照通过，最大顺序组成和误差 5.551115e-16。
同终点比较见 `air5_compensated_L1_20260926/dt2_dt1_matched.json` 和
`dt1_dt05_matched.json`（位于 `tests/gpu_validation/out/` 下）。
主流变量差异随时间步减小而减小，但痕量组分并非全部单调，不能据此宣称
所有变量满足形式收敛阶数。下一步执行 L2；L2/L3 尚未运行。

### 开跑前置条件

1. 验证 SSP-RK 当前/原始状态余量的加权传播，与 metric-weighted qsave
   的单位和所有消费者一致。保持原方程、精度及保正/组成阈值。
2. CPU/GPU 流场调用实际接入候选，定义边界覆盖、halo 与重复节点的余量
   所有权。未支持路径明确拒绝，不能静默沿用与 q 不对应的旧余量。
3. 本批关闭滤波，不扩大到过滤状态的补偿。旧 checkpoint 无余量字段：
   其 q 作为新的实验初态时可显式声明余量为零，所有 dt 对照必须一致；
   这不等于恢复历史未保存的低位。候选中途续算必须保存匹配余量，或停止
   并从冻结初态重跑，不能把清零后的续算当作连续轨迹。
4. 受影响默认/候选 CPU/GPU、NP1/NP2 短回放、共享面和内存检查先通过。
   同一候选可执行文件用于所有 dt；记录源码、输入、checkpoint 和二进制标识。
5. 长时诊断应能记录质量闭合、最小组分、T/Tv/p、化学接受/拒绝计数、
   失败 rank/step/stage；现有输出不足的部分先补齐，不能以稀疏快照声称
   检查了每个阶段。当前没有生产候选开关，不冻结候选可执行 SHA。

### 输出、比较与停止条件

- 首末步保存完整阶段快照。L1 如失败，仅围绕首次失败补局部诊断；不逐步
  写全场。关闭序列场、切片及无关平均输出，每组独立目录，禁止覆盖旧证据。
- L1/L2/L3 checkpoint 间隔分别拟定 50/200/1000 步。当前 CFL 日志依赖
  checkpoint 事件，不把间隔设成超过整个窗口的值。记录到的 CFL 必须 <1，
  不能据稀疏日志声称每步均已检查。AIR5 不使用仅适用周期算例的
  `ASTR_GPU_BENCHMARK_NO_FIELD_IO`；本批是稀疏 checkpoint，不是完全无 HDF I/O。
- 每个数值门槛失败即停，保留首个失败的 step/rank/stage，后续窗口不启动。
  状态非负、组成 128 epsilon、机制温度/压力域、Ev 可反演及原有物理边界
  不变量均保留。检查器旧 `2e-12` 闭合门槛更宽，不能替代物性接口的
  `128 epsilon` 顺序求和门槛。
- `check_air5_mach4_error_replay.py --matched-window` 可比较同二进制、
  同初态 NP2 的 2:1 时间步对；L1 分别比较 2/1 ns 与 1/0.5 ns。
  它当前输出的是诊断，不是完整的时间精度合格判据。逐分量检查全部 11 个 q、
  T/Tv/p 和速度，痕量组分单独缩放，不混合量纲，也不以接近零的速度分量作分母。
  没有预先冻结时间离散误差门槛前，只报告差异，不自动宣称时间收敛。
- 开放平板存在进出口及壁面输运，不能要求全域总质量/元素/能量保持常数。
  化学局部守恒与全域通量收支分别检查，未记录边界通量时不宣称全域守恒闭合。
- 最小 CPU 对照只做同初态短步和选定末态的同相位局部回放，不先提交全程
  CPU 长算例；候选余量必须一并传递，不能只比较 HDF 中的高位 q。

声明式配置保存在 `tests/gpu_validation/air5_long_window_plan.json`，状态为
`blocked-pending-full-flow-compensation`、`auto_launch=false`，现有驱动不读取
该文件。当前没有自动提交脚本或虚假的已启用候选命令。

## 起步网格与入口

`prepare_air5_mach4_case.py` 独立准备 `air5hbl`，不会打开激波顶面。
初始速度是有限厚度四次多项式种子：`f(s)=2s-2s^3+s^4`，`0<=s<=1`，
外部 `f=1`。`u=Uinf*f`，`v=w=0`，`T=Tv=Tw+(Tinf-Tw)*f`，
`rho=pinf/(Rmix*T)`，组分保持入口组成。
这不是可压缩双温相似解，必须先经 ASTR 预发展。

启动剖面以 `Re_delta_star=1000` 定标，位移厚度定义为
`integral[1-rho*u/(rho_inf*Uinf)]dy`。当前模型边缘黏度为
`5.40477883e-5 Pa s`，所得参考厚度 `0.37548214 mm`，种子总厚度
`0.97641532 mm`。预发展域 `80x12x2` 倍参考厚度，即
`30.03857 x 4.50579 x 0.750964 mm`。流经时间 `Lx/Uinf=9.65139 us`。
这些是起步参数，不是网格或入口物理收敛结论。

首轮网格上界 `63,63,7`，步长 `2e-9 s`。CFL 以实际输出为准，达到 1
或出现实际负组分、NaN、越界即停止。先进行短步 CPU/GPU 同相位比较，
再进行不超过一个流经时间的预发展试跑。确认趋势后才安排多流经时间收敛。
必须覆盖位移厚度、壁压和壁热通量的时间变化，不能仅凭任务正常退出判断稳态。

`air5_hbl_domain.dat` 是可选尺寸接口，首行为 `air5_hbl_domain_v1`，
第二行为 SI 单位的 Lx/Ly/Lz。无此文件时保留旧 air5hbl/air5sbli 的尺寸。
当前只用于内置 Cartesian 网格，不宣称验证外部曲线网格。

## 推进顺序与停止条件

1. 新配置数据检查、旧配置回归、根 CMake 编译。
2. 新平板 CPU/GPU 短步场、原始传感器、掩码与模型有效域检查。

计划顶面转折为 x=20 倍参考厚度。零入口偏转时几何落点约 x=45.734 倍
参考厚度；理想规则反射波重新到达顶面的 x 约为 85.8 倍参考厚度，超过

必须在激波接入前重算，不允许预先认定完整状态顶面适用于最终波系。

禁止直接用解析种子或缩放旧 HTR 初场开始长时 SBLI 并称为物理验证。
新出现的 CPU/GPU 不一致或模型域错误仍是停止条件，不能援引旧展向误差豁免。

### 已确认的下一候选约束（2026-09-24）

用户确认：保留 N-1 个独立质量分数，指组成满足总和为一后的物理自由度，
不指只存储或推进四个组分。保留现有总密度方程及全部五个组分守恒变量，
不增加第十二个守恒变量。五个组分对称构造候选通量，最终通量联合约束，
不再固定以 N2 余量覆盖状态或对流通量。

- 每个界面最终组分质量通量之和等于该界面的总质量通量。
- 各组分的修正由相邻单元保正预算约束，不再无条件采用所有组分的最小
  系数。相邻单元和 MPI 两侧必须使用同一最终界面通量。
- 不用推进后归一化、截零或浓度地板替代守恒及保正条件。
- 联合检查总能量与振动能的可容许性和通量相容性。质量闭合不等于压力
  平衡，不把逐点补能量当作已验证的修复。
- 固定总质量通量下的可行性条件及失败回退仍需推导。没有可行解时不能
  静默把残差交回 N2；也不能未经推导声称现有低阶流体/组分混合基态保正。
- 审查扩散、化学源项、滤波、边界和重启对组成约束的维护，避免只改对流
后仍由其他路径恢复固定 N2 闭合。保留现有默认路径用于受控对照。

实施顺序：明确联合预算及相容条件，完成 CPU 候选和最小算例，再同步 GPU
并检查 MPI 界面。先验收等压接触输运、痕量幅值扫描和低 N2 工况，随后
进行双温能量检查和既有 SBLI 短回放。所有门槛通过前不提升默认、不启动
长时生产。本节记录已批准方向，不表示联合限制器已实现或验证。

### 投影算术修复与小型 CPU 矩阵（2026-09-25，先前记录）

上一轮组分 NP2 的失败已由界面探针定位。RK2 全局界面 23，两侧高阶通量
与预算只有机器量级差异，二分参数却分别为 0.9608154111 和 0.9664230251，
映射总能量通量差约 3.394e-6。原因是高阶输入接近零，保正约束却要求有限
的组分通量重分配；输出中的正负抵消项远大于输入。旧投影以输入尺度检查

### 联合预算的实现约束与冻结门槛（2026-09-25）

新诊断只读取旧接触测试快照，不推进流场。由首阶段 q 重构显式六阶中心
通量及 LLF 通量，先核对中心通量散度与 ASTR `conv_raw`，再检查界面区间。
检查器使用固定质量截面上的线性加权通量极值，不使用带绝对可行性容差的
通用优化器。五组分采用相同规则，120 种索引置换和方向反转纳入测试。

对等温、等压接触面，除质量闭合外，组分携带的气体常数加权通量也必须
保持相容。固定总质量通量时，仅修正总能量不能同时恢复温度和压力。
现有接触快照的 CPU NP1/NP2、GPU NP2 均显示：界面 25 的逐组分低/高阶
连线区间容许质量闭合，但加权通量上限为约 2499.9999999998877，目标
为 2500，缺口约 1.12e-10，超过本次算术检查界限 7.11e-11。
这是线性约束可行性检查，不是最终物理误差大小的预测。

因此新候选不能只把原来的公共 alpha 换成五个独立 alpha，再投影回这些
连线区间。下一实现采用相邻单元的完整阶段预算构造允许区间：设低阶完整
RK 候选为 U_L，界面修正为 dF，更新系数为 cdt，则每单元的六个面状态为
`V_f = U_L + 6*cdt*sign_f*dF_f`，完整更新是六个 V_f 的平均。
映射坐标下 U_L 使用 Jacobian 加权状态，通量使用相同映射通量。
物种区间由界面两侧 V_f 的非负约束交集给出，而非限制在原低/高阶连线上。
两侧必须使用同一个最终通量。密度、振动能余量和去除动能后的平动能余量
仍须在同一 V_f 上检查，不能由质量区间可行推断双温可行。

在已保存的接触和低 N2 首阶段，六面预算区间均允许固定高阶质量通量及
气体常数加权通量约束。接触界面 25 的加权通量允许范围约为
2028.679--2963.670，包含 2500。这个较宽区间仅给出可行域，不能直接选
任意可行点，应选靠近原候选的修正，并联合约束携能通量。
一般非均匀温度、强激波及后续 RK 阶段尚未验证。无可行解时不得转移残差
给 N2、截零或静默切换未证明的流体/组分混合基态。

### 修复第一步：时序审查与 CPU 质量闭合基础件（2026-09-25）
